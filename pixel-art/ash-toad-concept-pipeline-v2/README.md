# アッシュトード 段階制作 v2

ユーザー指定の4段階をすべて保存した制作セット。

1. `01-concept.png` — ドット化を前提にしたコンセプトイラスト
2. `02-pixel-master.png` — コンセプトを基にした高密度ドット絵マスター
3. `03-reduced-guide-32.png` — マスターを32×32へ縮小した構図下敷き
4. `04-ash-toad-final-32.png` — 下敷きの比率を読み、32×32原寸で打ち直した完成稿

完成稿には縮小画像の画素を流用していない。縮小画像からは、背中から眼へ上がる
輪郭、後脚・胴・喉袋の面積比、接地線だけを読み取った。最終画像は11色、二値アルファ、
外周1pxアウトラインで構成している。

## 画像生成プロンプトの要点

画像生成には組み込みのImageGenを使用した。

- コンセプト: 右向きの低い洞窟蛙、石板状の背、琥珀眼、巨大な白い喉袋、
  上左光源、明確な色面、灰色背景、ピクセル化しやすい輪郭。
- ドット絵マスター: コンセプトの構図と解剖を固定し、硬い正方形クラスター、
  約18色、アンチエイリアス・ディザ・散らした質感なしの高密度ピクセルアートへ変換。

`build.py` は手打ち完成稿、工程比較画像、縮小下敷き、品質レポートを再生成する。
