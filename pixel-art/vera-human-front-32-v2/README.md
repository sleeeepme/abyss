## 品質確認

初回比較で腕・フード・脚の面が平らだったため、包帯の区切り、フード明面、装束の重なり、ブーツの反射を追加。二本の腕と手、二本脚、空の矢筒、顔の暗い開口、大弓を原寸で確認。元の概念画の細長い体型は、今回の参照に合わせコンパクトに変更。

外周約1px、内側は腕と胴・手首・ベルト・脚に暗線を入れる。布は青緑、革は暖色、骨は象牙色。各素材に広い面と小さな光を配置。描画格子は原寸1pxで統一。32pxで細かな指の本数までは表さず、手を独立したまとまりとして残す。

32px原寸、512px厳密16倍、アルファ0/255、16色以内、近似重複なしを検証。孤立判定は斜めの弦で意図的。アニメーション・ゲーム接続は対象外。背景可読性はプレビューで確認、ゲーム反映は未実施。

判定：初稿としてSHIP。採用確認前。
