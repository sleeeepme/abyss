# 眷属：発光アウトラインの霊体案

横幅+1前の小型化稿（kin-compact-v2、kin-compact-v4/restoredと同一）を使用。青白い1論理pxの輪郭と、その外側の淡い青い光を追加した。

本体の位置・形状を保つ。ウィスプのみ左右の青い端を既存の暗い輪郭色へ各1px変更し、発光との境界を補った。目・嘴・触手は描き替えていない。光だけ別レイヤーで作り、ぼかしは光に限定した。

- `spirit-preview.png`：6種の発光版、原寸併記。
- `comparison.png`：上が本体（ウィスプの左右修正を含む）、下が発光版。
- `wisp-preview.png`：左右の暗い輪郭を補ったウィスプの拡大表示。
- `native/`：発光を合成した24×24透過PNG。
- `body-16/`：16×16透過PNG。ウィスプの左右2画素以外は元のファイルを維持。
- `layers/`：本体・1px発光輪郭・淡い光・発光合成の24×24透過PNG。
- `kin-spirit-pngs.zip`：上記PNG一式。
- `build.py`：レイヤー作成と書き出しの正本。

24×24は光用の余白を含むキャンバスで、本体の拡大ではない。本体を(4,4)に配置しているため、描画時は元の16pxスプライトに対して左上へ4論理pxずらし、同じ1px倍率で表示する。既存CharacterArtへそのまま24pxを16pxに縮めて渡さない。

検証：合成時の本体画素一致、光の端切れなし。ウィスプの修正位置は16px本体上の(5,8)、(10,8)（0始まり）。暗色・中間灰色・明るい床色で目視し、目と嘴の暗い部分が残ることを確認。小さなシルエットの周囲へ光が加わるため、見かけ上の占有範囲は増える。

デザイン確認用。本編の描画・戦闘仕様は変更していない。
