# 眷属：小型化稿に発光アウトラインを追加

ユーザー指定の「一つ前」は横幅+1前のkin-compact-v2（kin-compact-v4/restoredと同一）を使用。6種の元の画素・色・目・嘴は維持する。

追加フィードバック：ウィスプの左右の端が発光と同化するため、16px本体の(5,8)、(10,8)を青から既存の暗い輪郭色 #1f2843 へ変更。各側1pxだけ補い、身体の形・目・発光レイヤーは維持する。

- 鬼火6×8、蝙蝠12×5、梟8×8、目玉12×8、骸骨8×8、海月8×8の身体を保つ。
- 身体の外側に1論理pxの青白色の光線。光線の外に弱い青い光を広げる。内部の目・口の暗い色へ光線を入れない。
- 光は身体と別レイヤー。余白4pxを付けた24×24キャンバスを使い、光が切れないようにする。身体自体を24pxへ拡大しない。
- 本体のピクセルは整数倍率のみ。ぼかしは光レイヤーだけに使う。
- 原寸・拡大・暗い背景と中間灰色で確認。輪郭が明るいだけの白い塊にならず、6種それぞれの特徴が残ることを優先。
- まず静止のデザイン案。ゲーム本体への反映・新しい動作は追加しない。
