# ヴェラ第二形態・正面64px／16bit戦闘モンスター調

ユーザー指定：64×64原寸、ロマンシング サガ3のモンスターのテイスト。Pixel Art Studioによるコード描画。既存キャラクターの画像やピクセルを転用せず、ヴェラの大弓・空の矢筒・四肢・正面の構えを継承する。ゲーム未反映。

## 成果物

- front-64.png：64×64px原寸、RGBA透過。
- front-512.png：8倍ニアレストネイバー、512×512px、RGBA透過。
- preview.png / preview-dark.png：明暗背景での確認用。
- build.py：Pixel Art Studioを呼ぶ再生成用正本。
- silhouette.png / palette.png / stats.json：確認資料。

## 描画方針

紫に寄せた陰影、青緑の布、暖色の骨。明部の輪郭を素材色へ置き換え、均一な黒い縁を弱める。筋肉・骨板・布を原寸のクラスターで描き分ける。16色に制限し、ランダムノイズや画像縮小は使わない。

参照画像を探索した資料：[RS3のモンスター画面](https://thaao.net/romasaga3/battle/?p=boss)、[RS3公式販売ページの画像](https://store.playstation.com/en-gb/product/EP0082-CUSA13947_00-ROMANCINGSAGA3HD)。画風の解釈は本作向けの提案。

## 目視・出力検証

- 輪郭／縮小時の読みやすさ：大弓、背、四肢を確認。胴体は正面。後脚2本を内側、太い前脚2本を外側へ配置。右前足と弓下端は意図的な重なり。
- 色面：主要部分は複数pxのまとまり。目と斜めの弦は意図的な1px。半透明0、色数16、近似重複0。
- 光源：左上。骨の明部は暖色、体の影は紫。ハイライトは広さを変え、輪郭全周を同じ陰影で囲まない。
- 輪郭：原寸1px。素材色を明側に使用。混合ピクセル密度なし。
- 孤立判定2点は斜めの弦上。不要な足先の点を削除。
- 出力：64px原寸と512px厳密8倍拡大、アルファ0/255を検証。
- アニメーション：対象外。
