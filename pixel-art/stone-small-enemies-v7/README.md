# 小型アッシュトードとダストスパイダー

## 出力
- `ash-toad-32.png`: v6の造形を保持して25×17pxへ詰めた32×32透過PNG。
- `dust-spider-32.png`: 実体28×19px、32×32透過PNG。
- `lineup.png`: ハウンド・小型トード・蜘蛛の8倍比較。下段は灰・暗・明背景で原寸表示。
- `toad-size-comparison.png`: トードの旧・新比較。
- `build.py`: グリッド編集・パレット整頓・出力の正本。

両方12色、二値アルファ、孤立画素なし。トード284px（v6は367px、約23%減）、蜘蛛295px。
ハウンドの最下部3行は地面影なので、新作は足の接地点y=20に合わせた。

## 制作方法
トードはv6原寸の眼・喉・後腿を残し、胴／顎の冗長な3列と2行を削除。補間縮小なし。
蜘蛛は組み込みImageGenにハウンド・這う死者・v6トードを直接画像参照させ、粗いドット絵案を生成。
`spider-prompt.txt`に全文を保存。生成画像は正確な32pxグリッドではなかったため、目視した粗い32×19グリッドの各セル中心を抽出し、腹部などの4列を詰めてパレットへ割り当てた。完成PNGと生成画像は別物であり、実行時に高解像度画像を縮小表示する方式ではない。

## 作成対象の資料
- https://elthen.itch.io/2d-pixel-art-spider-sprites
- https://sanctumpixel.itch.io/spider-pixel-art-character

両方の公開プレビューをブラウザで観察。大小2つの胴体、前側に集まる脚、屈曲する関節、脚間の空間を参照した。外部蜘蛛素材は生成モデルへ入力せず、ゲームへ複製していない。
設定は`proto/enemy-compendium.html`の「細い長脚の蜘蛛。砂色」を参照。

新規画像はレビュー用。既存ゲームアセットと苔玉は変更していない。
