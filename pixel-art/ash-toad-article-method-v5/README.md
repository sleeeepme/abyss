# アッシュトード article method v5

[モシナラ「岩や氷をドット絵で描くコツと手順」](https://moshi-nara.com/18037/)の
基本工程を、アッシュトードの32×32スプライトへ適用した試作。

## 工程

1. 使用範囲をアッシュハウンドと同じ28×19pxに固定
2. 単色シルエットで眼丘、後腿、腹下、前脚を確定
3. ベース色へ最暗部を大きく配置
4. 中間値と明部を連続した面として追加
5. 最後に1px輪郭を加え、上側輪郭だけ一段明るく調整
6. グレースケールの明暗関係を維持して12色へ置換
7. Tiny RPG犬、アッシュハウンド、這う死者と同倍率で比較

## 以前の案から直した点

- 実体高23pxから19pxへ縮め、アッシュハウンドと同じ占有サイズにした
- 材質ごとの色分けより先に、強い影と明部を作った
- 全周同色の輪郭をやめ、上側に明るい輪郭を混ぜた
- 長い水平な色帯を減らし、明部を小さな連続クラスターへ整理した
- 後腿、脛、前脚、喉袋を陰影でも分離した

完成稿は32×32、実体28×19px、12色、二値アルファ、孤立画素なし。
