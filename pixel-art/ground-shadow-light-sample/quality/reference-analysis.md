# Ground shadow reference analysis

- **表示条件**: 白地に大きく拡大された静止画像。中心の黒い楕円から、外側へ数十pxかけて連続的に透明になる影で、輪郭線は見えない。
- **シルエット文法**: 接地点が最も濃く、横方向は厚く、先端へ行くほど細く・薄くなる。影の外周に硬い多角形やドット状の段差はない。
- **クラスター文法**: ドット絵ではなく、半透明値を連続的に変えた1枚のぼかし画像。中心から外側へ暗→中間→透明の三層以上がある。
- **色と材質**: 色は青みを含む黒 #070914 だけ。材質は地面へ溶ける拡散影で、中心だけをベタ黒にしない。
- **アニメーション**: 参照は静止画。ゲームでは影画像の形を固定し、主人公ライトと反対方向へ回転させる。キャラ／アイテムの上下移動中も影の基点は地面に保つ。
- **維持する品質**: 硬い影輪郭を残さないこと、濃度が連続的に落ちること、接地点と投影方向が読めること。
- **独自化する箇所**: 円形ではなく、ゲーム内の方向性ライトに合わせて前後で太さと濃さが変わる短い楕円形にする。

不採用: 多角形の本体に外周だけを足す方式。中心に硬い輪郭が残り、参照の拡散影に見えない。
不採用: 全対象の影を主人公の向きと反対へ揃える方式。対象と光源の位置関係が影へ反映されない。
通過条件: 影の画像だけを拡大しても、中心から端まで不透明度が段階なく連続して下がること。
通過条件: 敵・仲間・道具の影は主人公から放射状に外へ伸び、主人公自身の影だけは向きの反対へ伸びること。
