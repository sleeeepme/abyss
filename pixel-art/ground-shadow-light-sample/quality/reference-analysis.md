# Lighting and shadow reference analysis

- **参照**: HOLLOWFLUX — The Living Vein (`https://tideglass-drowned-vein.openai.chatgpt.site/`)。実プレイ画面と公開クライアントの描画処理を2026-09-16に確認。
- **表示条件**: 内部描画は高さ270pxの低解像度キャンバスで、画面へ最近傍拡大される。暗い環境光の上へ複数光源を加算する。
- **光源文法**: 主人公光は、足元を保証する近距離全周光と、向いている方向のソフトな円錐光を合成する。円錐は中心線だけを硬く抜かず、約66度の明部から約128度の半影へ連続的に落ちる。
- **遮蔽文法**: 壁は光源から対象画素までをグリッド追跡して完全遮蔽する。キャラはスプライトの形を床へ投影せず、円形の遮蔽物として扱い、光源から見た背後57px以内の光量を減らす。半影は距離とともに少し広がり、先端で消える。近い遮蔽物を最大7体に制限する。
- **接地影**: キャラ本体には、光源方向と無関係な短い横長の足元影だけを持たせる。長い影は黒い画像を足すのではなく、照明レイヤーから光を引くことで表現する。道具は照明の遮蔽物にせず、足元影だけを持つ。
- **色と材質**: ABYSS固有の青緑パレットは維持する。参照から引き継ぐのは、暗い環境光、近距離全周光、方向性ライト、壁遮蔽、円形キャスターによる半影という役割分担。
- **アニメーション**: 主人公の向きにライトが追従する。遮蔽物が動くと背後の減光領域も毎フレーム追従するが、接地影の形と向きは変えない。
- **処理負荷**: 低解像度ライトバッファ1枚へ光と遮蔽を集約し、最後に1回だけ本体へ合成する。キャスターは距離順に最大7体。スプライトごとの影画像生成、毎フレームの画像読取、Canvas filterは使わない。
- **独自化する箇所**: 光色はABYSSの青緑、距離はタイル寸法へ換算する。仲間も物理的な遮蔽物として扱うが、アイテムは可読性と負荷のため遮蔽物にしない。
- **ABYSS向け調整**: 参照式をそのまま使う初稿は光が強く影も長く見えたため、2回の実画面調整を経てライト合成強度を0.39から0.25へ下げる。キャラ背後の減衰は参照の20〜57内部pxから13〜38内部pxへ短縮し、方向・半影・遮蔽物強度は維持する。

不採用: キャラスプライトのアルファマスクを横倒しにして床へ投影する方式。参照ゲームの方式ではなく、キャラごとのテクスチャ生成とキャッシュ管理も増える。
不採用: キャラごとに長い黒い影画像を直接描く方式。光量の減衰ではないため、床から浮いて見える。
通過条件: 接地影は光源方向を変えても足元の同じ位置・形を保つ。
通過条件: 敵または仲間の背後だけライトが弱まり、遮蔽物の手前と本体は暗くならない。
通過条件: 壁の向こうへ光が漏れず、ライトバッファの生成は1フレーム1枚、キャスターは最大7体に収まる。
