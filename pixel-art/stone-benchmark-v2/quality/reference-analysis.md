# 基準の修正
ユーザー添付写真1.jpg（630×500）を見た目の基準とする。ページの無劣化PNG（628×500）で画素ブロックを再計測した結果、表示倍率は正確な4倍。添付JPEGの横2px差は表示画像化によるもの。
小型敵の実体はおよそ横22〜31×高さ17〜22px。左中央の犬は約31×18px、左下の跪く赤い敵は約22×20px。クロウリングデッドの30×20pxはこの範囲内。
クロウリングデッドは実体30×20px、32pxセルで設計。頭9×9px、短く太い腕、各素材2〜3段、黒い輪郭1px。内部面の単画素散布を禁止。灰色背景で正確な4倍表示として比較する。
無劣化PNGで小型3体を計測すると背景を除く色数は、跪く敵10色、スライム13色、犬17色。小型敵の範囲は10〜17色、中心値として13色を本作の固定予算とする。色相はABYSS側のものを維持する。
旧案の細密原画を縮小する方法・64pxへの拡大による回避は不採用。今回まず1体で形と色面を再設計。アニメーションなし。参照の犬と跪く敵と新作を同じ約3倍で比較する。
