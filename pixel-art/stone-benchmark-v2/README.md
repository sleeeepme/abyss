# 基準合わせ・クロウリングデッド

ユーザー添付の Tiny RPG Character Pack 02 画像を直接参照し、内蔵ImageGenで新規生成、Pixel Art Studioで実寸グリッドとパレットを整理。

- 原寸: `crawling-dead-32.png`（32×32、キャラ実体30×20px、13色、透過0/255）
- 拡大: `crawling-dead-32@8x.png`
- 比較: `comparison.png`（ユーザー提供参照の抜粋と新作。どちらも1ドットを正確な4×4pxで表示）
- 原画: `source.png`
- 最終生成プロンプト: `prompt.txt`
- 再生成: `build.py`

今回は1体の方向性修正。旧11種はこの基準への修正未実施、ゲーム組み込みなし。比較画像の参照抜粋は検討用でゲーム素材ではない。

確認: 灰色背景で参照の獣・跪く敵と正確な4倍で比較。以前の64px案の細かい表面模様を廃し、大きな頭、短い腕、連続した面、1px外線を使った。無目的な白い縁と半透明画素なし。参照小型敵は10〜17色で、中央値に近い13色へ固定した。配色自体はABYSS側を維持。
