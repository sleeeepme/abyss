2026-10-13。原画は16×16の配置枠のまま、実際の絵の幅・高さをそれぞれ2論理ドット小さく描き直した。普通の画像縮小は使っていない。

|鬼火|8×10|6×8|

`comparison.png` の上が現行、下が比較案。各カードの大きい表示は8倍、小さい表示は原寸・2倍。配置枠とピクセル倍率をそろえている。

- `native/`：原寸16×16透過PNG。
- `runtime-4x/`：既存の保存形式に合わせた64×64透過PNG。各画素を整数4倍にしたもの。
- `original/`：現行正本から書き出した原寸比較画像。
- `build.py`：6種の格子正本。既存tools/npc_px.pyのレンダラーとパレットを使用。
- `quality/report.json`：各種の実描画寸法・色数・配置。

現行の色と6種のモチーフを維持し、特徴を残せる画素配置へ整理した。細部の許容量が最も小さい蝙蝠は、翼と中央の顔を優先。鬼火は目が輪郭に埋もれないよう、顔の側面に炎の青を使った。梟は目・嘴・左右の足、骸骨は左右の眼窩と顎を整理した。

デザインの比較稿として保存。現行のゲーム画像・埋め込みデータ・戦闘仕様は変更していない。実ゲームの重なりや発光下での識別性は未検証。
