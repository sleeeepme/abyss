# 眷属6種：幅・高さを各2論理px削る比較案

正本の参照：tools/npc_px.py の KIN / KIN_PAL。実装はproto/index.htmlのCharacterArtで64px PNGを1マス相当に表示。原画は16×16の論理格子、保存時は4倍。

今回は絵の不透明領域の幅と高さを各2px減らす。16pxの配置枠、1ドットの画面上の大きさ、描画の中心を維持。普通の画像縮小は使わず、格子を描き直す。既存の6種と色の役割を残す。

- 鬼火8×10→6×8：非対称の炎先端と2つの暗い目。炎の白い明部は上側へ寄せる。
- 蝙蝠14×7→12×5：横に広い翼、中央の頭、左右の尖った翼端。翼膜と顔の明暗を分ける。
- 梟10×10→8×8：耳状の羽、左右の明るい顔盤、暗い目、中央の黄色い嘴。
- 目玉14×10→12×8：白目と緑の虹彩、暗い瞳。脇の赤い部分は白目より弱く小さく。
- 骸骨10×10→8×8：頭蓋の幅、2つの眼窩、狭い顎。上端の青い火と骨の色を分ける。
- 海月10×10→8×8：丸い傘と細い触手。目と触手を混同しない。

原寸、整数倍、暗い背景、6種を並べた識別性で確認する。小ささの制約が最も大きい蝙蝠は翼の形の識別を優先する。輪郭を太らせて細部を埋めない。

ゲームの正本・埋め込み画像を変更する前のデザイン比較稿。生成元のコードを再利用し、変更範囲は今回の6種の格子と比較用出力に限定。
