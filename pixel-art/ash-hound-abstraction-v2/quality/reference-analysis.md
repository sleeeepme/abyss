# アッシュハウンド：小サイズでの抽象化試作

2026-09-26。基準は承認済みash-hound-tinyrpg-v1と、TinyRPG犬の既存復元資料。復元資料は公式の原寸素材そのものではない。

- 32×32原寸。承認済み画像は影を含む28×19px。今回も横28px程度、接地y=21付近。原寸・4倍・8倍で比較する。
- 左上の巻き尾→低い横長胴→右端の大きな顎。脚や尾を伸ばさない。腹下の空間を維持。
- 目は1px、口は暗い大面＋少数の明るい牙。細かい毛や全ての歯を説明しない。
- 暗い胴を一塊にし、灰色の明部は上面へ限定。肋骨は長さの違う小さい3群、背中から腹まで均等な縞にしない。
- 輪郭は1pxを基本に、クリッピング・外周の抜けを確認。暗い内部の重なりと外周線幅は区別する。
- パレットは承認済み12色の機能を維持。灰・骨・燠・目の役割を分離し、平均化や自動減色で決めない。
- 既存のコードで描かれた正本を別稿として改修。大きい絵からの縮小は使わない。生成AIによる候補の縮小も行わない。
- 静止画。アニメーションの品質は今回評価しない。
- 不採用パターン：平均化された口の色塊、細長い脚、灰色の弱い外周、画素数だけを合格理由にする、ディテールの均等配置。
- ユーザー採否と制作上のレビュー判定は別。元の採用素材は置換しない。
