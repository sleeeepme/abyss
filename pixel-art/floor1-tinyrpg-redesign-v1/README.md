# 1階アッシュ系モンスター Tiny RPG再設計 v1

1階の通常出現テーブルを基準に、アッシュハウンドの完成版と同じ描画文法で
ダストスパイダー、アッシュトード、ストーンボアを再設計した。

- 原寸32×32px、透明背景、二値アルファ
- 原寸グリッドへ直接作画（大きな絵からの縮小なし）
- 外周は暗い紫黒の1pxアウトライン
- 左上光源、面でまとめた陰影、12色以下
- 3つの識別要素を優先し、孤立した装飾ピクセルを使わない

## 識別要素

- ダストスパイダー: 横長の低い姿勢、4組の脚間の抜け、粉を被った腹部と錆色の頭
- アッシュトード: 地面へ沈む後脚、頭頂の眼、発射予兆になる白い喉袋
- ストーンボア: 短い胴、高い肩、身体の半分を占める石頭と一本牙

`floor1-lineup-neutral@8x.png` は、承認済みアッシュハウンドと据え置きの苔玉を
比較用に並べたもの。苔玉の原本は変更していない。

`build.py` を実行すると原寸、8倍確認画像、段階ゲート、検査用レポートを再生成する。
