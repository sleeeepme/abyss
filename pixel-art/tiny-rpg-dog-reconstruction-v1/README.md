# Tiny RPG dog reconstruction v1

ユーザー提供のTiny RPG Pack 02紹介JPEGから、4倍表示された犬の論理グリッドを復元し、32×32原寸へコードで再構成した私的ベンチマーク研究。

- `tiny-rpg-dog-32.png`: 32×32透過PNG
- `tiny-rpg-dog-32@8x.png`: 透明背景の8倍表示
- `tiny-rpg-dog-32-neutral@8x.png`: 参照と同じ中間灰色での8倍表示
- `comparison.png`: 復元参照グリッドとコード作画の比較
- `quality/01-*`: シルエットゲート
- `quality/02-*`: 大色面ゲート
- `quality/report.json`: グリッド一致検査

正規配布データではないため、ゲーム素材として使用・再配布しない。購入済みPNGまたはAsepriteファイルがある場合は、それを基準に色とフレームを再検証する。
