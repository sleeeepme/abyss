# Tiny RPG Hellhound reference analysis

## 表示条件

- 入力は630×500 JPEG。犬は4倍の最近傍表示と推定。
- グリッド位相は全体座標でx≡1、y≡0（mod 4）。
- 犬と接地影の復元範囲は論理32×24、可視部は約28×19px。
- 背景は中間灰色。JPEG圧縮による近似色を原画色として採用しない。

## シルエット文法

- 左から高い二重巻き尾、低い横長胴、右端の大きな頭と顎。
- 四脚は短く、腹下の三つの負の空間で分離。
- 背中は水平直線にせず、小さい毛束の段差を連ねる。
- 頭は胴より高く、口の矩形クラスターが視線の焦点になる。

## クラスター文法

- 外周は1論理px。黒に近い色を外周と口腔へ共用。
- 胴は大きな暗紫クラスター。小さな明部を上面と脚へ限定。
- 赤褐色は尾の傷と口の中へ反復し、キャラクター固有色を作る。
- 歯と眼は1〜3pxの高明度記号。連続した細線にはしない。

## 色と材質

- JPEG近似色を11の機能色へ統合。
- 役割は外周／深部影、胴影、胴基色、胴明部、赤影、赤基色、赤明部、最高輝度。
- 光は左上。下面と口腔が最暗、背中と鼻先に限定的な明部。

## 維持する品質

- 28×19px程度の情報密度。
- 大顎、短脚、巻き尾の比率。
- 1px輪郭と、大きな胴クラスターに対する小さい赤・桃色アクセント。

## 不採用パターン

- 大きい絵を縮小して輪郭を作る。
- 2px以上の外周、脚を同幅の縦棒で並べる、胴全体へ均一な毛ノイズを散らす。
- JPEG圧縮で生じた近似色を別色として保存する。
