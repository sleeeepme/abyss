# Ash Hound — Tiny RPG grammar v1

Tiny RPG犬の原寸グリッド、輪郭リズム、クラスター密度を維持しながら、ABYSSのアッシュハウンドへ改変した32×32スプライト。

- `ash-hound-32.png`: 原寸透過PNG
- `ash-hound-32@8x.png`: 最近傍8倍表示
- `ash-hound-32-neutral@8x.png`: 中間灰色背景での確認用
- `quality/candidate-sheet.png`: A〜Cの内部比較
- `quality/01-*`, `02-*`: シルエット・大色面ゲート
- `quality/report.json`: サイズ、色数、透過、採用案
- `build.py`: 再生成可能な正本
