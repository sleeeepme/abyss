# アッシュハウンド — Tiny RPG犬型アレンジ

## 維持する文法

- 32×32原寸、可視部約28×19px、1px外周。
- 高い巻き尾、低い胴、短い四脚、右端の大顎。
- 腹下の負の空間、暗い大面積の胴、小さい高明度の口。
- 11色前後の機能パレット。孤立した装飾ノイズは使わない。

## アッシュハウンド固有化

- 腹を持ち上げて痩せた胴にし、突進姿勢を強める。
- 胴へ不均等な3本の露出肋骨クラスターを置く。
- 背中に灰色の連続クラスターと二つの短い逆毛を追加。
- 眼は鈍い琥珀色の1px。口だけを低彩度の燠色にする。
- 尾の赤い傷は灰化した骨色の割れへ変更する。

## 候補判定

- Aは元犬の体積が残り、アッシュハウンドの痩身性が弱い。
- Bは腹下の負の空間、肋骨、肩の高さが最も読みやすい。
- Cは頭蓋表現と尾の欠けが強く、犬よりアンデッドへ寄りすぎる。
- 採用: B。
