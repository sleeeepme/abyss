# アッシュトード: 原寸ルールの別種への応用

## ユーザー評価

「カエルは前回の造形の方が良い」。v9の新造形は不採用。以後はv8の持ち上がった頭・丸い後腿の構成を維持する。色面整理の評価と造形変更の評価を混同しない。反映案は `../../ash-toad-form-restore-v10/`。

参照はTinyRPG正規原寸Demon A / Blood Monster Aの分析、承認済みAsh Hound、今回のDust Spider v9。種の外形はelesrech Frogs | Pixel Monsters 17の実表示を観察。二つの眼丘、首なしの頭胴、広い喉袋、折り畳んだ後腿を読む。https://elesrech.itch.io/frogs-pixel-monsters-17

世界観の指定「座った大蛙。喉が膨らむ」。既存v8の灰紫の皮膚、琥珀の目、灰白の喉を引き継ぐ。原寸32x32、可視22x15程度、接地y=20。v8の縮小・行列削除・画素コピーをしない。

外形: 右向き斜め、体高を抑える。左の大きな後腿と右の短い前脚の間へ負の空間。喉は顎から腹へ続く面にして独立した円球にしない。

色面: 皮膚の広い灰紫基色、下面の暗い紫、局所的な灰色明部。喉は暗い灰褐色と骨色。目は1pxの琥珀色2点。皮膚全面の斑点や細かい陰影段階を増やさない。近黒の1px外周と口・腿の折り目を共用。

先に3つの単色シルエットを比較。主要面→陰影・焦点→1px外周の漏れ検査。TinyRPGとハウンドと蜘蛛に同倍率、原寸3背景で比較。静止画のみ。

## 目視と修正

3案ではBの二つの眼丘が種の識別に有効。Aは横向きの生物全般に見えやすく、Cは頭の下面が大きくなりすぎる。Bを採用し、左後腿の丸い塊、暗い折り目、右前脚の間の空白を維持。

初稿で眼丘間の凹みと腹下2画素に色が露出。該当する3画素だけを暗色へ修正した。外への輪郭膨張・一括輪郭追加はなし。頭・胴の皮膚を大きい連続面にし、喉は灰褐色と骨色の2色面に整理。

試作提出可: 原寸でカエルの姿勢、二つの眼丘、後脚と喉を読める。明・中・暗背景で確認。外周着色漏れ0、半透明0、孤立画素0。8色は今回の材質構成の結果で、TinyRPG全キャラ共通の制限ではない。参照と同じ表示倍率で皮膚の面・暗い部位分離・局所的な目の明色を比較した。動き・ゲーム背景上での検証、ユーザーによる採用は別。
