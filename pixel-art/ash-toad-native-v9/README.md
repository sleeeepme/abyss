# アッシュトード v9

TinyRPGの正規原寸分析と、ダストスパイダーv9で行った原寸作画の工程をカエルに適用した試作。

32×32透過PNG、可視領域22×15px、8色、229不透明画素。v8と可視寸法・接地位置(y=20)は同じ。灰紫の皮膚、灰白の喉、琥珀の目を引き継ぎ、原寸の記号グリッドから描き直した。旧画像の画素コピー・縮小・行列削除はない。

- `ash-toad-32.png`：原寸透過PNG。
- `ash-toad-8x.png`：中間灰色背景の8倍表示。
- `comparison.png`：TinyRPG正規原本、ハウンド、蜘蛛v9、トードv8、今回の同倍率比較。下に原寸3背景。
- `stages.png`：外形・主要色面・完成案。
- `quality/silhouette-options.png`：横向き、二つの眼丘、喉袋強調の3案。
- `build.py`：再生成可能な原寸作画ソース。

右向き斜めのBを選択。頭頂の眼丘2つ、首のない頭と胴、丸い後腿と折り畳んだ脛を形の基準にした。陰影は大きな面で置き、喉の明部と琥珀色の目を焦点にする。遠い側の四肢は胴・手前の四肢へ重なって隠れる姿勢。腹下の抜けで後脚と前脚を分離。

外周着色漏れ0、半透明0、孤立画素0。原寸3背景と6倍・8倍で目視確認。画風の完全一致を数値で保証するものではなく、今回の応用試作として提示。アニメーションとゲーム内検証は未実施、ゲームへ未組み込み。
