# 石の層6F以降のボグ系4体

設定はproto/enemy-compendium.htmlのFAM.slime.min=6とZAKO.slime。石の層1–10Fの後半に出る通常敵。採用済みトードv10と暫定採用蜘蛛v9、ハウンドTinyRPG版、這う死者v2が画素密度の基準。TinyRPG正規原寸の材質別色面の分析を使う。8色固定ではなく各材質の役割で8–11色を目安にする。

## 対象固有の観察

- 蛇: https://elthen.itch.io/2d-pixel-art-snake-sprites — 表示画像で立ち上がった頭と低い尾、首の細さ、くねる体を観察。リードサーペントはS字の首と開いた巻きの負の空間、黄褐色の腹側、1pxの眼。鱗の点描を省く。
- 袋・触手: https://elthen.itch.io/2d-pixel-art-jellyfish-sprites — 小さい傘と下がる細い触手、局所的な上面の光。シルトジェリーは濁った袋、下の暗い口、長さの違う5本の触手。ピンクの配色や正方形の原型は流用しない。
- 蟲: https://elthen.itch.io/pixel-art-worm-monster-sprites — 環状の胴、曲がりで間隔が変わる節を観察。ブロートグラブは設定の横向きに膨らんだ芋虫へ転換。3つの大きい膨らみ＋後端、小さい硬い頭、短い足。
- ボグクロウラー: https://elthen.itch.io/2d-pixel-art-froghemoth-sprites と先に観察したFrogs Pixel Monsters17、承認済み這う死者の大きな掌を比較。Froghemothの触手や眼柄は採用せず、設定「水底を這う四つ足。掌が先に出る」から低い体と大きい手前の掌を設計する。四肢のうち奥の二肢は暗く一部隠す。

## 制作基準

原寸32×32へ作画。幅16–27、高さ13–22程度の可視領域。紹介イラストや旧64px案の縮小をしない。部分ごとに手で記号グリッドを描き、外形→材質面→明暗→眼・掌・節・触手の順に確認。黒に近い外周1px。細い末端は暗い1px線、各部の重なりだけに内部の暗い面。半透明やぼかしなし。

各個体の主役: 掌、首と巻き、袋と触手、膨れた節。明部をこの識別に使い、全身へ散らさない。採用済み参照と同倍率、原寸3背景、工程一覧を保存する。今回の4体は候補であり自動的な承認・ゲーム組み込みはしない。
