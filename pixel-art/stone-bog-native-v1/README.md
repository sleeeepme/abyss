ボグクロウラーは小さい頭と大きな掌、蛇は細いS字首と巻きの隙間、ジェリーは濁った袋と垂れた触手、グラブは膨れた節と短脚を識別点にした。ブロートグラブは初稿の長い脚を短縮し、甲虫に見えやすい姿勢を修正。蛇の腹側の露出画素は元のセル内で暗い輪郭に置換し、外形を膨張させていない。

全4体で外周の着色漏れ0・孤立画素0・半透明0。これらは画像の整合性検査であり、TinyRPGとの画風一致やユーザー承認の代替ではない。ゲーム背景上の見え方・アニメーションは未検証。
