# 前稿の口を維持した待機アニメーション

- ユーザーFB：abstraction-v2より前の口の造形の方が分かりやすい。基準を承認済みash-hound-tinyrpg-v1に戻す。
- 32×32原寸、既存12色。大顎の口腔・牙・燠色の配置を保ち、静止フレームの顔は元データと一致させる。
- 待機のみ。接地位置を固定し、胸が1px持ち上がった後に頭が追従。尾の先と顎は一拍遅れて動き、静止の長い間を置く。
- 胴と頭の上下移動は最大1px、尾先も1px。画像全体の上下動や拡大縮小で代用しない。肩・脚付け根・顎の接合を原寸で補う。
- 既存コードのvariant_bから生成。接地影をプレビュー用に分離し、素材自体は身体だけの透過PNG/GIF。
- 輪郭・脚の接地・色面・口の識別をフレーム一覧と再生で確認する。TinyRPGの静止資料から動作を推定した試作であり、公式アニメーションの再現ではない。
- 元の採用素材は置換しない。
