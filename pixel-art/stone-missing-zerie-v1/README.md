# 石の層の未作成モンスター 11種

2026-09-18制作。`index.html` が比較ページ、`overview.png` が一覧、`sprites.zip` が透過PNG一式。

主案は全種 **64×64 / 右向き寄り待機1枚**。`native-32` は縮小比較用、`native-64` が主案。32pxでは顔や祈りの手が潰れるため最終主案にしなかった。各フォルダの `@8x` は最近傍8倍の確認画像。

## 対象

|区分|対象|
|---|---|
|不死者|クロウリングデッド、フォールンカンパニー、プレイングデッド、デッドスプリンター|
|湿地系|ボグクロウラー、リードサーペント、シルトジェリー、ブロートグラブ|
|石の層の異形|粉挽き、無音|
|条件出現|アビスの巡回者|

設定確認元: `proto/enemy-compendium.html`、`proto/index.html`。既存アートのある灰獣4種・モスボール・大灰ガエル・ヴェラは新規制作の対象外。通常エリートは15F以降のため今回の色違い制作対象なし。巡回者の時間段階差分は未作成、基礎姿のみ。

「無音」は設定どおり黒一色。「巡回者」の石と鉄の重装甲は、歩いて追い続ける行動からの新規デザイン提案。装備の損傷、布色、祈りの装飾などは今回の造形解釈。

## 制作・再生成

公開ベンチマーク: https://zerie.itch.io/tiny-rpg-character-asset-pack-02

暗色輪郭、誇張した頭・手、重なりの黒線、材質の面分けを観察し、ABYSSの設定から個別に新規生成。参照製品のスプライト自体は成果物に含まない。今回の64px版は公開参照より細部密度が高い。

- `sources/`: 各モンスターの生成原画。消さないこと。
- `prompts/`: ImageGenに渡したプロンプト。
- `manifest.json`: 名称・寸法・原画の由来。
- `build.py`: Pixel Art Studioによる透過整理・最近傍縮小・色数整理・輪郭・プレビュー出力。
- `quality/mechanical-report.json`: 全22PNGの寸法、アルファ、色数、余白。
