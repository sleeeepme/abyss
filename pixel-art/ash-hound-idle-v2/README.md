# アッシュハウンド：脚・胴・顎の接続修正版

32×32、12色、7コマ、1.78秒の待機ループ。承認済みの口を維持し、脚は肩・股関節から描き直した。

- `ash-hound-idle-32.gif`：原寸透過GIF。
- `ash-hound-idle-8x.gif`：8倍プレビュー。
- `ash-hound-idle-sheet.png` とJSON：224×32の7コマシート、フレーム時間付き。
- `frames/`：通常・頭非表示・部位色分けのコマPNG。
- `index.html`：旧版と修正版の同期再生、接続確認、コマ送り。
- `build.py`：正本。四脚の付け根と接地位置、頭・胴・尾の画素マスクを明示。
- `quality/report.json`：全コマの脚の経路・胴との重なり・全体の連結検査。
- `quality/review.md`：見つけた問題、修正、検証と限界。

ゲーム本体や既存の採用素材は置換していない。
