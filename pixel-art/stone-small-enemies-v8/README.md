# 小型モンスター v8

32×32 透過 PNG。v7 を元にネイティブ画素の行・列を詰め、輪郭と顔を修正した版。

|対象|v7 の可視領域|今回|色数|
|---|---|---|---|
|アッシュトード|25×17|22×15|12|
|ダストスパイダー|28×19|24×16|10|

蜘蛛は砂色の中間階調をまとめ、暗い紫系の構造とまとまった腹部の明面を強調。トードは後肢・喉・目を残し、目の明度を調整。

輪郭は透明領域へ膨張させず、既存シルエット内の外周1画素を暗色に統一。薄い脚の先端も含め、上下左右で透明部分に接する着色画素の輪郭漏れは0。半透明・孤立画素も0。機械検査は画風の一致を保証するものではない。

`lineup.png` はアッシュハウンドとの同倍率比較と、3背景の原寸表示。`before-after.png` はv7との比較。`build.py` が再現用ソース。ゲームへの組み込みは行っていない。
