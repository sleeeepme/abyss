# アッシュハウンド再設計基準

- 設定: アッシュ系／乾。「粉と乾いた石」。痩せた犬であばらが浮き、走ると粉が舞う。AIは直線突進型。
- 方向・姿勢: 右向き。頭を低く前へ出し、背から尾まで水平に近い。待機でも突進直前に見える前荷重。
- サイズ: 32×32セル、実体は横29×縦20px前後。Tiny RPG参照の犬とクロウリングデッドに近い占有面積。
- 大形: 楔形の頭、露出した胸郭、細い腹、長い四肢、ちぎれた灰の尾。
- 色: 13色。石灰色、青紫影、鈍い土色、琥珀眼。色相ではなく色数と面の分け方を既存ベンチマークに合わせる。
- 線: シルエット内側の暗紫1px輪郭。肋骨は3本の短い連結線。眼は暗い眼窩＋連結した琥珀1px。
- 不採用: 旧16px版の単純拡大、毛の細線、灰粒の散布、外側へ膨張させる太い輪郭、滑らかな縮小。
