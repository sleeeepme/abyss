# 石の層・追加4体の基準

参照はユーザー添付 `写真1.jpg` と、承認された `stone-benchmark-v2/crawling-dead-32.png`。

- 表示条件: 32×32セル、キャラクター実体は横22〜30×高さ17〜27px。比較表示は1ドット=4×4px、背景#6e6e6e、足元はy=28〜29付近。
- シルエット: 大きい頭または胴を一塊、短い四肢・触手を中形、目や指先を小形とする。負の空間は手足の間に1〜3px。
- クラスター: 外周はほぼ黒の1px。内部の陰影は3px以上の連続面を基本にし、単画素は目だけ。曲線は1,1→2,1→2,2程度の階段。
- 色: 各1体ちょうど13色（透明を除く）。共有暗線1色、主要材質3〜4色、第二材質3色、骨・目など3〜4色。色相はABYSS固有でよい。
- アニメーション: 今回は右向き寄り待機1枚のみ。
- 維持する品質: 添付の大きな頭・短い胴、少ない面、密な黒線、承認済みクロウリングデッドの画素密度。
- 独自化: 敵ごとの姿勢と設定、灰青・苔緑・濁り黄緑の色相。

対象: プレイングデッド、デッドスプリンター、ボグクロウラー、シルトジェリー。

不採用: 高解像度絵を単純縮小した細線、64px化、細かい擦れやテクスチャ、指を一本ずつ長く描く、13色を満たすためだけの孤立画素。

## 最終比較

- SHIP: 4体とも32×32セル。本体は22×25、28×22、29×20、24×25pxで参照の小型敵と同じ範囲。
- SHIP: 各13色、半透明0、孤立画素0。詳細は `pixel-quality.json`。
- SHIP: 1ドット=4pxの比較で、承認済みクロウリングデッドと同じ輪郭幅・色面密度。

- 未検証: アニメーションと実ゲーム背景上の可読性。今回の納品は待機1枚のデザイン候補。
