# Ash Hound — native 32×32 redesign

Tiny RPG参照の塊感へ合わせ、アッシュハウンドを32×32原寸で直接再設計した。

- `ash-hound-32.png`: ゲーム用原寸。32×32、実体30×22px、13色、透過PNG。
- `ash-hound-32@8x.png`: 最近傍8倍の確認用。
- `comparison.png`: Tiny RPG参照、承認済み密度基準、新作の正確な4倍比較。
- `build.py`: すべての形と色を最終32px座標へ直接描く再生成手順。縮小処理はない。
- `quality/`: 参照分析、シルエット、統計、品質ゲート。
