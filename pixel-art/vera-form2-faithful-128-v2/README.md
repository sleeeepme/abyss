# ヴェラ第二形態・元絵準拠128px v2

Pixel Art Studio使用。直前に提示した中心サンプリング版を基に、透明境界へ混入した白〜灰色のノイズ22pxを除去。元絵は同じイラストのロスレスPNG。正本は build.py と reference.png。

前ターンから継続していた128px化を完了し、素材別の32色パレットへ整えた。ブロック多数決方式より中心サンプリングの方が顔・手・布を残せたため、直前の比較候補を採用。元絵の骨板・手指・四肢の形を大まかな多角形へ置き換えていない。

- front-128.png：128px原寸RGBA透過。
- front-512.png：厳密4倍の512px版。
- sampled-clean.png：減色前のノイズ除去済み128px版。
- preview-dark.png / preview-light.png：明暗背景で確認。
- verification.json：除去座標・色数・検証記録。

検証：ノイズ除去工程が記録した22px以外を変更しないことを差分確認。暖色の骨・弓・爪は対象外。32色、半透明0、原寸128pxと厳密4倍を書き出し検証。明暗両方の背景で外周を目視確認。原寸の斜めの弦などは4近傍の孤立判定に入るが、意図した形として保持。色の近似判定2組は青寄りの布影と暖色寄りの体影のため保持。

初稿として納品。ゲーム未反映。64px化は128px版の形の確認後。
