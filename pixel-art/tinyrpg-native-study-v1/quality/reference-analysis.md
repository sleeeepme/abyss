# 原寸素材による分析（制作前）

資料: Zerie Tiny RPG Character Asset Pack 02 v1.01 無料版。2026-09-20公式無料配布経由で取得。Demon A / Blood Monster A の影なし Idle 第0フレーム。購入データではなく正式な無料版。犬は既存JPEG復元であり原本検証の対象に含めない。

- 同じ100×100セルでも本体はDemon A 20×20px、Blood Monster A 20×15px。色数はそれぞれ21、8。共通の11色制限を原作者のルールとしない。
- 人型: 大きな耳状の角と頭、短い胴脚、下を横断する大きな刃。黒で眼窩と腕・武器の重なりを分離。肌、角、刃に別々の色群がある。
- 軟体: 左上から右下へ傾く口腔、下に広がる3つの接地群。面積の大きい赤い体と紫の口腔、1〜3px幅の白い牙。明赤は2画素だけ。
- 共通: 黒の外形を基本とし、大きな面に局所的な高輝度アクセント。1pxは牙、眼、材質の接点、輪郭の段差に用途がある。色の数とクラスターの数を混同しない。
- 例外: 両者とも上下左右に透明が接する非黒画素が2画素ある。原本の仕様を「機械判定ですべて閉じる」ルールで上書きしない。ゲーム側の厳密な閉じた輪郭要件とは別に扱う。

習作: 2体とも原寸のパレット記号グリッドを再構成し照合。次に材質の役割ごとに灰・骨・煤色へ変更。第2段階ではDemon Aの左角、Blood Monster Aの上顎の牙だけを変更する。変化の領域外が一致することも検証。新生物を描き分ける能力の証明ではなく、局所変更を制御する実験。

表示: 32×32の分析用セルへ等倍で置き、下端y=26で揃える。8倍最近傍拡大と原寸を併記。制作は原寸のみ。静止画のみ、元のアニメーションの時間・動きは今回の評価対象外。
