## 修正した制作ルール

- TinyRPGを固定色数にしない。観測した2体は21色と8色で異なる。材質の数と各色の役割を基準にする。
- 面積の大きな基色を確保し、明色の1pxは目・牙・材質の接点に割り当てる。全身の均等な点描で密度を増やさない。
- 外形と内部の黒い分離面を区別する。「外周1px」と「黒の塊がどこでも1px幅」は異なる。
- 原本にも上下左右の境界で非黒の画素が各2画素ある。自動輪郭補修の合格を画風の合格に置き換えない。ユーザーの閉じた外周要件は、原作者の観測結果と分けて記録する。
- 小型化は新しい寸法で頭・胴・四肢・負の空間を設計する。行列削除を完成処理にしない。

## 現時点での判定

原本の読み取り・再構成と、限定した部分の編集は確認できた。素材にないカエル・蜘蛛などへの造形転換、元アニメーションの再現、ゲーム内可読性は今回未検証。次はこの規則を固定し、1体のシルエット段階から別種への応用を検証する。
