# アッシュトード native v3

Tiny RPG犬、完成版アッシュハウンド、這う死者を基準に、32×32原寸だけで制作した試作。
コンセプトイラスト、縮小下敷き、自動生成アウトライン、高解像度原画は使用していない。

## 工程

1. 黒一色の原寸シルエットを6案制作
2. 実体サイズ、画素数、充填率、腹下と脚間の抜けを比較
3. C案（29×20px、343px、充填率59%）を採用
4. 外周・胴・石頭・喉袋の4色面を配置
5. 成功作と同じ10〜13色域へ展開
6. 原寸、8倍、左右反転、成功作との同倍率比較で確認

完成稿は32×32、実体29×20px、12色、二値アルファ、孤立画素なし。
