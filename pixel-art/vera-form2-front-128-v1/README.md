# ヴェラ第二形態・正面128px 初稿

Pixel Art Studio使用。正本は build.py。128×128pxの整数格子上で多角形・1px線・細部を描画する。64px画像の拡大やAI生成画像の縮小は使用しない。形の配置は64px試作から継承し、128px格子で輪郭、顔、指、骨板、布の面、足先を描き直した。

- front-128.png：128×128px原寸・RGBA透過。
- front-512.png：4倍ニアレストネイバーの512×512px・RGBA透過。
- preview.png：灰色背景の確認画像。
- silhouette.png：輪郭確認。
- palette.png / stats.json：16色パレット・検証結果。

ゲーム未反映。前案・採用済み素材の上書きなし。

## 目視検証

- 輪郭：大弓、幅広い背、四肢が判別可能。正面の顔と胸を維持。弓の下端と右前足は意図した重なり。
- 読みやすさ：64px試作と128pxプレビューを確認。明るい弓・骨と暗い胴体を分離。内側の支持脚2本と外側の前脚2本を確認。
- 陰影：左上光源。広い色面を主体とし、顔、指、弦だけに1pxの細部を使用。影は青寄り、骨の光は暖色。細い平行ハイライトの多用なし。
- 色：16色、近似重複なし、半透明0。輪郭は原寸1px。斜めの弦は階段状になり、一部が4近傍の孤立判定に入るが、連続した意図的な線。足先の不要な孤立1pxは除去。
- 書き出し：128px原寸、512px版の厳密4倍拡大、アルファ0/255をコード検証。
- アニメーション：今回対象外。

判定：初稿として納品。キャラデザインの採用確認は未実施。
