# ダストスパイダー v9 — 原寸ルールの別種への応用

TinyRPG正規原寸2体の分析を、新しい蜘蛛の造形へ適用した静止画試作。`build.py`が画素構成の正本。v8の素材の縮小・行列削除・取り込みは行っていない。原寸32×32、可視領域23×15、8不透明色、156不透明画素。

- `dust-spider-32.png`: 透過原寸。
- `dust-spider-8x.png`: 中間灰色背景の8倍確認画像。
- `comparison.png`: 正規TinyRPG 2体、承認済みハウンド、v8、今回を6倍と原寸3背景で比較。
- `stages.png`: 外形・主要面・仕上げの比較。
- `quality/silhouette-options.png`: 腹部の高さ・大きさを変えた3案。

## 今回固定した描画ルール

腹部・頭胸部・細い脚を別の大きさの塊にする。砂色の腹部に広い基色面と紫褐色の下面、上面に4画素の明部を置く。琥珀の目2画素・骨色の牙2画素を焦点にする。近黒の外周は1px、細い脚先は暗い線そのものにする。内部の暗色で部位の前後を示す。

8色は今回必要な材質役割の結果であり、TinyRPG全体を8色に制限する意味ではない。前回の10色から単純な減色処理をしたものでもない。

## 検証

同じ画素密度、下端y=20で比較。ハウンドのみ元の地面影が下に残る。明・中・暗の背景を原寸で確認。外周の着色漏れ0、半透明0、孤立画素0。3案から高い腹部のBを選択し、目・牙が脚に隠れる問題、後脚付け根の1px穴と露出色を修正。

画風の完全一致を数値判定したものではなく、別種への応用案。足数は頭胸部へつながる奥4本・手前4本として構成するが、根元の一部は胴と手前脚に隠れる。アニメーション、ゲーム内背景上の視認性は未検証。ゲームへは未組み込み。
