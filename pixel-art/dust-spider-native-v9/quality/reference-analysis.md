# 新種への応用: ダストスパイダー

参照: 前工程の正規TinyRPG Demon A (20x20,21色) / Blood Monster A (20x15,8色) の原寸分析。承認済みAsh Hound。生物の外形はElthenのSpider Spritesの実表示で、小さな頭胸部と大きな腹部、屈曲して外へ張る脚、脚間の空白を観察。
https://elthen.itch.io/2d-pixel-art-spider-sprites

設定: proto/enemy-compendium.htmlの「細い長脚の蜘蛛。砂色」「足音を真似る」。直近の小型化要望を維持し、可視領域24x16px程度を目標。32x32原寸で作画。元のv8画像の縮小・行列削除はしない。

シルエット: 右向き斜め。左に大きい腹部、右に小さい頭胸部。脚は頭胸部から4対を設計し、奥側は胴の後ろに隠す。腹部の輪郭を脚と接線で潰さず、手前の脚先を分離する。

色面: 砂色の腹部が主面、紫褐色の下面が影。頭胸部と脚は同じ色群を共有。目は琥珀色の1px記号、牙は骨色の小さな塊。色数の固定自体をTinyRPGの再現指標としない。

輪郭: 近黒の外周1px。細い末端は輪郭そのものを1pxで表現。太い付け根の内側にだけ面色を置く。ユーザー指定の輪郭抜けなしを検査するが、黒い線が太りすぎないかも目視確認。

比較工程: 腹部形状の違う3シルエット→主要色面→明暗・目・牙。原寸、8倍、TinyRPG正規原本とハウンドとの比較。静止画のみ。

## 反復と目視結果

初稿FIX: 奥脚を上に出しすぎて大きい輪ができ、頭部周りが蟻の触角に見えた。胴を上げ、奥脚も下の接地点へ向けて描き直し。3案ではBの腹部が頭胸部から最も読み分けやすい。

色面FIX: 手前脚が目と牙の上を横切った。脚の付け根の前に顔が来るようレイヤー順を変更。腹部の明部は広すぎたため上面の4pxへ限定し、下側にまとまった影色を置いた。後脚の交差にできた小さな閉じた穴を除去、露出した脚色1pxを手で暗色へ修正。

試作提出判定: 外形・向き・大きい腹部と小さい頭・屈曲脚が原寸で読める。上面、下面、顔、脚が別の面として残る。細部は目と牙へ限定。原寸3背景で確認。半透明0、孤立画素0、外周着色漏れ0。参照にある広い基色面と局所的な明部を適用できたと判断。ただし画風の完全一致・ユーザー採用を意味しない。材質は砂色の表面として表現し、写実的な砂粒や毛は加えていない。動きとゲーム実背景での検証は対象外。
