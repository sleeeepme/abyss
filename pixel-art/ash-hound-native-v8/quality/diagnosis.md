# v8 visual diagnosis — reject

**Verdict: FIX / 作り直し**

## Silhouette

- 四足獣までは読めるが、犬種らしい胸、肩、腰、飛節の差がない。胴と脚が矩形の接続に見える。
- 頭と首の負の空間がなく、箱状の頭を胴へ貼った形になっている。
- 尾の二股は読めるが、付け根から先まで同じ太さで、曲線の段差リズムがない。

## Clusters

- 主要色の境界が水平・垂直の長方形へ偏り、同色クラスターが形の面を説明していない。
- 肋骨の3本線が同じ長さ・同じ間隔で並び、胸郭ではなく柵に見える。
- 口内が大きな矩形で、顎・歯・口角の形に分解されていない。

## Outline and value

- 暗色4色だけで全可視画素の約66%を占め、胴・脚・首の境界が一塊に潰れる。
- 外周100%を最暗色で囲ったため、参照の軽い上面と重い下面の差が出ていない。
- 明部が頭と脚先へ散り、上左光源に沿った一つの大きな明部になっていない。

## Next construction rules

1. 犬の骨格を頭・胸郭・骨盤・前脚・後脚の5塊で一色設計する。
2. 矩形ツール主体をやめ、輪郭の各ランを1,1,2,2,3の段差で手修正する。
3. フラット2値版で犬・前傾・短脚が読めるまで陰影へ進まない。
4. 胴の明部を一つの連続クラスターにし、肋骨はそのクラスターを切る暗部として2本までにする。
5. 口は上顎・口腔・下顎の3クラスターで構成し、単一矩形にしない。
6. 統計合格を画質合格として扱わない。
