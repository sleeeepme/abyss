# アッシュハウンド v8 — Tiny RPG犬型への再設計

## 参照から採用した造形文法

- 高く巻いた二股の尾、低く横長の胴、大きな箱型の頭、短い四脚という比率。
- 黒紫の輪郭と胴の大きな暗色面。細線を増やさず、短い縦線で脚と肋骨を分ける。
- 顔では口を最大の情報にし、暗赤色の口内へ少数の明るい歯を置く。
- 実体は30×22px、13色。セル内に1px以上の余白を持つ。

## ABYSS側の固有要素

- 石灰色・青紫影・灰褐色の体色。
- 胴の三本線で「あばらが浮く」を示す。
- 右向きの大きな顎と前寄りの重心で直線突進型を示す。

## 制作方法

32×32の最終座標へ直接作画した。高解像度原画、画像生成、縮小、グリッド復元は使用していない。
