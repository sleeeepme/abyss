# アッシュハウンド v9 — Tiny RPG犬型・原寸直接作画

## 参照から採用した造形

- 高く巻いた二股の尾、低い横長胴、大きな頭と顎、短い四脚。
- 体表は細密線でなく大きな同色クラスター。脚は腹下の負の空間で分離する。
- 顔の主情報は大きな口。暗い口腔、赤褐色の内側、少数の明るい歯で構成する。
- 背中は小さな段差で輪郭を作り、長い直線や矩形だけにしない。

## ABYSS固有要素

- 石灰色、青紫影、灰褐色、燠色の口。
- 胸郭の2本の不均等な骨色クラスターで「あばらが浮く」を示す。
- 右向きの大顎と前寄りの頭部で直線突進型を示す。

## 制作工程

32×32の最終座標へ直接作画。`01-silhouette`、`02-flat`、完成の順に各工程を保存して目視した。高解像度原画、ImageGen、縮小、画像復元は使っていない。

## Quality gate

- SHIP: 一色シルエットで巻き尾・低い胴・大頭・四脚が読める。
- SHIP: 腹下の3つの負の空間で4脚が分離している。
- SHIP: 上左光源。胴上面の灰褐色と頭上面の灰色が大きな連続クラスター。
- SHIP: 13色、二値アルファ、孤立ピクセル0。
- SHIP: 外周は1px。上面のみ暗紫へ一段明るくするセレクティブアウトライン。
