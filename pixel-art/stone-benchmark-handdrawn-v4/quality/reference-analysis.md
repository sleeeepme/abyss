# 手描き32px版

前案はImageGen原画の縮小であり不採用。今回は生成画像を入力に使わず、`build.py`で32×32の座標へ直接シルエットと色面を描く。

- 基準: ユーザー添付 Tiny RPG Character Pack 02、承認済みクロウリングデッド。
- 32×32セル。本体は22〜30×18〜26px。足元y=28前後。
- 外周と重なり線は共通の黒紫1px。曲線は1〜3px単位の階段。
- 頭・背中・袋を最大形、手足・触手を中形、目・歯を小形とする。
- 各13色。色数は細かなノイズではなく、材質ごとの影・中間・明面へ割り当てる。
- 単画素は眼のみ許容。内部の陰影は2〜6pxの連続クラスター。
- 右向き寄り待機1枚。アニメーションなし。

対象: プレイングデッド、デッドスプリンター、ボグクロウラー、シルトジェリー。

## 最終確認

- SHIP: `build.py`の32px座標から直接生成。入力画像・高解像度原画・縮小処理なし。
- SHIP: 参照、承認済みクロウリングデッド、新作4体を同じ4倍表示で比較。
- SHIP: 全4体13色、半透明0、孤立画素0。黒紫1pxの外周と、2〜6pxの連続した内部面。
- SHIP: 合掌、前傾走、巨大な掌、濁った袋と触手が単色シルエットでも判別可能。
- 未検証: ゲーム背景上の可読性、待機以外のアニメーション。
