# ヴェラ第二形態：リグで動かすドット絵（2026-10-19）

- `concept-4x.png`：ユーザー提供の絵（4倍拡大）。`native.png` はそれを原寸 119×76 に戻したもの。
- `map.png`：ユーザー指定の脚の色分け（6倍）。緑＝胴、橙・黄・青・紫＝脚、白い点＝関節。
- `rig.py`：リグ本体。脚＝関節の点をつないだ骨（IK で足先を地面に固定）、頭の枝＝ここで定義した骨。
  回転は RotSprite（8倍に拡大して回して戻す）で、輪郭の補修・穴埋め・切れ端の接続まで行う。
  `render(cf)` の cf：by/bx（胴のずれ）、tip（足先の目標）、thigh（黄の太もも）、ant（枝の反り）、glow（目）、broken（壊れた部位）。
- `motions.py`：待機・歩行・予兆・攻撃・被弾のコマ列（`build(R)`）。
- `gen.py <combo>`：脚の壊れ方（0〜15）ごとに全コマを `out/v2g_<combo>.png` に書き出す。
  ゲームへの埋め込み（cave-look.js の `const VERA2=`）は、combo 0 を base、1〜15 を base との差分（消えるドットは #ff00ff）にした PNG。
