# 武器・属性エフェクトの本体接続

採用した `proto/ally-effect-study.js` の演出をゲーム本体へ接続した。

## 武器種の対応

| 装備base | 演出 |
| --- | --- |
| `great` | 両手剣・大剣 |
| `mace` | 戦槌 |
| `spear` | 槍・刺突 |
| `bow` | 弓 |
| `sword`, `axe` | 剣・斧 |
| `dagger` | 短剣 |
| `staff` | 魔弾・杖攻撃 |

近接攻撃は `swing` に実際の装備baseを保持し、`game-feel.js` が対応する演出を選ぶ。弓と杖は従来の弾速・射程・当たり判定を保ち、移動中の弾へ採用済みの矢または魔弾の見た目を追従させる。

## 属性の対応

追加属性がある場合は `elemOf(st)` が選んだ最大の追加属性を攻撃色へ使う。追加属性がない杖は魔法色、その他の物理武器は無属性色になる。

命中時は `feelImpact` に確定したダメージ種別と追加属性を渡し、炎・雷・冷気・魔法・無属性の専用ヒットを対象座標へ生成する。敵への命中と、敵から主人公・仲間への被弾の両方で同じ属性規則を使う。

変更は描画イベントの種類、色、表示時間だけに限定し、ダメージ式、攻撃速度、弾速、射程、当たり判定、敵AIは変更していない。
