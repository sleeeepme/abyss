# 武器技エフェクト案 V13 — 剣・槍・斧・弓

対象は `WEAPON_ARTS` の剣・槍・斧・弓・短剣・戦鎚・杖・大剣、各3技。威力、範囲、当たり判定は変えない。承認済みの通常攻撃描画 `AllyEffectStudy.render` を直接再利用し、倍率・向き・回数・発動前の小さな閃きだけで技の範囲と命中順を読みやすくする。

| 武器 | 技 | 実データ | エフェクト案 |
|---|---|---|---|
| 剣 | 居合 | 3.4マス踏み込み、通り道へ1回 | 通常の剣軌跡を1.18倍にし、踏み込み後の一閃だけを見せる。 |
| 剣 | 回転斬り | 半径2.7、全周1回、ノックバック | 通常斬撃と同じ太細、欠け、3段グローを使い、中心から等距離の円軌道を一周させる。 |
| 剣 | 多段斬り | 前方100度、3回、0.16秒間隔 | 通常の剣軌跡を右下がり、右上がり、横薙ぎの順に表示する。最後だけ1.13倍。 |
| 槍 | スウィング | 半径2.9、2回、0.2秒間隔 | 刺突線は使わず、通常攻撃と同じ細い穂先が円周を二度薙ぐ。 |
| 槍 | ショットランス | 長さ7、幅0.6、貫通 | 通常の槍刺突を1.28倍にし、同じ描画の細い副軌跡を少し先行させる。 |
| 槍 | ドラグーン | 1秒消失後、半径6.5内の単体へ急襲 | 上昇と急降下を、向きを変えた通常の槍刺突で表す。 |

| 短剣 | 乱斬り | 前方120度、3回、0.12秒間隔 | 通常の短剣軌跡を三方向へ素早く重ねる。最後だけ1.12倍。 |
| 短剣 | ダンシングソード | 6秒間、半径1.9を周回 | 通常の短剣軌跡三つを本人の周囲へ配置し、6秒間の代表区間をループ表示する。 |
| 短剣 | ミラージュ | 2.6秒間無敵 | 本体を半透明にし、左右へ離れながら消える二枚の残像で当たらない状態を示す。 |
| 戦鎚 | ダブルアタック | 前方95度、2回、0.2秒間隔 | 通常の戦鎚衝撃を上下へずらして二度打ち込む。 |
| 戦鎚 | 癒し打ち | 前方打撃、周囲を最大HPの9%回復 | 通常の戦鎚衝撃後、黄緑の十字だけを本人と周囲の味方へ配る。 |
| 戦鎚 | ホーリーシールド | 攻撃を1回無効化 | 戦鎚の短い発動閃光から、一撃分を示す六角盾を短く残す。 |

| 杖 | フレイム | 前方70度、2.5秒、0.4秒間隔 | 参考画像の床の橙色ブルーム、横広の黄白核、非対称の炎舌、弧を描く火片を再構成する。扇形に8箇所を時間差で着火し、各炎を約1.1秒残す。 |
| 杖 | アイシクルエッジ | 長さ5.5、3回、0.2秒間隔 | 地面の予兆線から三列の氷棘を0.2秒刻みで突き出し、根元へ円形の霜煙を出す。 |
| 杖 | ライトニング | 周囲半径3.2、3秒、0.4秒間隔 | 通常の魔弾で発動し、細い雷線と承認済みの雷ヒットを範囲内へ時間差で落とす。 |

| 大剣 | 大回転斬り | 半径3.2、2回、0.22秒間隔 | 大剣らしい太い円軌道を0.22秒間隔で二周させる。 |
| 大剣 | 地走り | 前方70度、距離5、ノックバック | 参照の Earth Wave を31フレームに分解し、連続する土塊の基部、前方へ傾く棘、小から大への隆起、頂点後に低い瓦礫へ潰れる崩壊、後方へ飛ぶ角張った粒を再構成する。9本の棘を0.043秒刻みで発生させる。 |
| 大剣 | レイジングアッパー | 前方単体、強ノックバック | 下側の細い始点から上側の太い先端へ伸びる切り上げ軌跡を出し、敵を同じ方向へ押し上げる。 |

居合は移動中の本体を約0.07秒で消し、移動先で約0.09秒かけて戻す。残像は移動開始から0.22秒で連続的に消す。技専用の追加は発動直前に0.12秒だけ出る小さな白黄の閃き。属性色・ヒットエフェクトは通常攻撃と同じ経路を使う。
