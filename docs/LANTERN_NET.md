# ランタンの光と暗がり（ドットの網）

2026-09-24。ユーザーが送ってくれた録画（ランタンの周りを数段の明るさに切り、段の境だけ 4×4 の網でつなぐ）に合わせた。

## 見た目の決まり
- 光の強さを主人公からの距離で決め、**5段**に切る。段の中はべた、段の境だけ網（Bayer 4×4）。網の1点＝絵の1ドット（`TS/16`）。
- 光は壁で止まる（`feelLightRay` の128本）。向いている側へ少し長く伸びる。キャラの背後には網の影（`feelLightCasters`）。
- 暗がりは画面の外周も含めてここで決める。旧い「なめらかなビネット」は使わない。
- 闇の段には薄い点の格子を残す（真っ黒にしない。参考の録画と同じ）。
- **キャラの周りは暗がりを抜く**（ユーザー指定）：主人公は半径1.35マスで完全に、仲間は0.95マス・強さ0.86、敵は0.87マス・強さ0.78、ボスは体の大きさ。
- **UI は暗がりの上**（ユーザー指定）：名前・Lv・HP帯・ボスの予兆・攻撃の予兆リング・守護陣の数字。
- 暗がりの濃さは全段 0.72 倍、中央の抜けは 1.3 倍（ユーザー指定）。
- 色はランタンの青緑（`#74c6a4`）のまま（暖色も試したが、青い床に乗せると灰色になった）。
- 床のマス単位の明暗（層の `lightR`）は止めた。明暗はこの網だけ。`lightR` は光の届く距離の倍率（`lightR/14`、0.8〜3）に使う。
  枷「暗幕」（`blinded`）の床の暗さは今までどおり。

## 作り
- `game-feel.js` の `FEEL_LANTERN`（数値はここ）、`drawPlayerLight`（光の計算と足し色）、`drawFeelDarkness`（暗がり）。
- 光の強さは4ドットおきの格子で計算して間を直線でつなぎ、段に切るのと網は1ドットずつ。キャラの抜きはキャラの周りの四角だけ塗る。
- `index.html` の `draw()`：床の直後から主人公を描き終えるまで `_uiQ` に UI を控える（`label()` は自動で控える。HP帯などは `uiLater(fn)`）。
  `drawPlayerLight` → `drawFeelDarkness` → 控えた UI を描く、の順。
- `?lantern=old` で旧い光（なめらかな光＋ビネット）に戻せる（見比べ用）。
- 重さ（ヘッドレスの目安）：約2.6ms/フレーム。

## 部屋の隅の地霧・漂う埃・虫（同日）
- ユーザー指定：マップに舞う粒を「大気中の埃や虫」に、部屋の隅に地霧のような薄いもや。霧は「なめらか」の案（網は掛けない）。
- 地霧：床1マスごとに四方の壁の近さを数え、直交する二方が近い所（角）だけ濃く、壁沿いは薄く、通路と部屋の真ん中はほぼ0。
  1ドットごとに補間し、横に長くゆっくり流れる雲の模様を掛ける（濃さは0.04刻み、最大0.38）。床の層（キャラより下）に描くので、ランタンの暗がりで自然に暗くなる。
  3フレームに1回、画面より少し広い範囲を床に貼り付けた座標で作り、その間はずらして貼るだけ。色は層ごと（`FEEL_MIST_COL`）。
- 埃：1ドットの粒70個。床と一緒に動く。明かりの中の粒だけ白く光り、ときどき瞬く。
- 虫：部屋ごとに霧の一番濃い角に羽虫の群れ（6割の部屋、6匹）。主人公の明かりの縁を回る蛾が1匹。
- `game-feel.js` の `FEEL_AMBIENT`・`drawFeelMist`（`drawFeelArtGround` の最初）・`drawFeelAir`（本編の `drawAir` から呼ぶ）。
- `?ambient=old` で旧い粒（層ごとの四角い粒）に戻せる。霧の計算はヘッドレスで約3ms（3フレームに1回）。
