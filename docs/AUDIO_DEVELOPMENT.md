## 2026-10-02 音色改訂 V2

ユーザー方針：UI以外の安易な音階・ピッチ下降を避け、GB音源の範囲で衝撃・材質・臨場感を出す。レベルアップはファンファーレ。

- 非UIの18音を独立した発音レシピへ置換。会心・パリィ・盾は整数倍ではない2つの固定周波数と短いノイズで金属の接触を作る。消滅は崩れ、ボスは段階的な瓦解、戦闘不能は低い衝撃から装備の擦れへ。取得・消耗品・階層移動も通知メロディーを撤去。
- `audio.js` の `textures` が正本。1つのリストが1つのGBチャンネル。同チャンネル内の発音区間は重複させない。矩形波は11-bit周期・標準duty、ノイズは実在する分周設定の15/7-bit LFSR、音量は64Hzの段階変化。PCM素材・FM・追加リバーブは使わない。出力フィルターとクリック抑制用の短い端フェードは近似で、実機エミュレーションではない。
- レベルアップは2矩形波・1.28秒のオリジナル祝奏。各音符を発音し直し、最後の和音を残す。管理画面の余韻を短くしても終止まで再生する。優先度を96から80へ変更し、被弾90・防御82・パリィ95には割り込ませる。
- 金属音は矩形波2声＋ノイズ1声を使う。既存の同時イベント数・チャンネル枠・距離減衰・間引き・音量設定を維持。UIと戻るの音声バッファはV1と完全一致。
- 管理画面冒頭に6音の改訂試聴ボタンを追加。保存済みの音量・ON/OFFは維持。ページのV2表示とスクリプトの版番号を更新。
- 検証：ブラウザ15項目通過（短い余韻設定でファンファーレ終盤が残り、被弾が優先されることを追加）。`audio/gb-game-v2/render-check.mjs` で20音の振幅、チャンネル内の非重複、ノイズ設定、UI同一性を確認。`raw/` のWAVはミキサー適用前の確認用音源。聴感と実機ハードウェアの確認を自動テスト済みとは扱わない。

以下はV1時点の記録。V2の音色・長さ・レベルアップ優先度は上記が最新。

## 正本と入口

- `proto/audio.js`：GBの矩形波・LFSRノイズによる20音の合成、発音調停、音量設定。GB実機のサイクル精密エミュレーションではない。波形メモリchは未使用。
- `proto/audio-game.js`：既存の成功イベントと音源の接続。ゲーム末尾で演出・ダッシュ・セーブのラッパーより後に読み込む。元の戻り値を保持する。
- `proto/sound-admin.html` / `sound-admin.js`：個別試聴、カテゴリ音量、個別ON/OFF・音量・最短間隔、減衰、混戦の試聴、設定JSONの入出力。
- 2026-10-10：ユーザー依頼でゲーム右上の「音設定」ボタンと埋め込み管理パネルを削除。管理ページは `sound-admin.html` を直接開いて使用する。ゲーム内の効果音接続は維持。
- `audio/sfx-study-v1` は前段階の3方式比較用試作。今回のゲーム内20音は上記JavaScriptを正本とする。

足音、継続ダメージ、通常の敵攻撃予備動作、毎フレームの画面更新、仲間の被弾・レベルアップには音を付けない。UI音は操作の受付音であり、購入等の成功を保証する通知音ではない。

## 混戦の標準値

- 全体音量35%。攻撃70%、重要結果90%、探索65%、UI60%。個別音量をさらに乗算。
- 効果音イベントは同時2件。管理画面で1〜3件。矩形波は最大2声、ノイズは最大1声。これらは設定で増やせない。複数声を使う音もあるため「2件＝2声」とは限らない。
- 16msの短い集約窓で優先度順に処理。同じ音・同じ主体区分の候補は1件へまとめる。最大32候補。後で順番に鳴らす待ち行列は作らない。
- 通常音は1秒8件まで。優先度80以上は3件の余裕枠を持つ。設定可能範囲は通常音3〜12件/秒。
- 同じ音は標準90ms〜2秒の最短間隔。攻撃カテゴリ75ms、仲間全体350ms、その他カテゴリ35msの共通間隔も適用。
- 優先度：死亡100、ボス99、レベル96、パリイ95、被弾90、防御82、技75、UI60、攻撃40台、通常命中30、通常撃破24。仲間の通常イベントは優先度を25下げる。
- 枠が不足した際は低優先音を約12msで消してから重要音を開始。高優先音・同優先音を連続して奪わない。余った候補は捨てる。
- 仲間25%。距離係数 `1 / (1 + (distance / 3.5)^2)`、8マス超は無音。音量がほぼ聞こえない候補は再生しない。
- 重要音の間はその他の音を30%へ下げる。重要音終了＋80ms後から時定数70msで復帰。
- 余韻は元の長さの50〜100%に調整。各音の後半を指数減衰。GBのノイズが鳴りっぱなしにならないよう、攻撃音は約75〜230msを中心とする。
- 高域を6.2kHz付近から緩め、コンプレッサーを通す。バッファをキャッシュし、ゲーム乱数は消費しない。

## スマホ・保存

音声はユーザー操作後だけ開始し、それ以前のイベントは破棄する。Web Audio未対応・開始失敗・ストレージ制限でもゲームを止めない。バックグラウンド化で音源を停止し、復帰後の操作で再開する。

設定の保存先は `localStorage['abyss.audio.v1']`。ゲームのセーブデータとは独立。同一オリジンの他タブ・iframeにはstorageイベントで反映する。他端末や異なるURLのゲームへは自動同期しない。JSON入出力で移せる。音設定パネル自体はセーブに含めない。

試聴サイトと同じサイトの `/play/index.html` に今回の音付きゲーム、`/play/sound-admin.html` に管理ページを配置する。以前の別サイトのセーブを自動移行しない。
