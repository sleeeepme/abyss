1. **遊び味を買い切りに寄せているのは意図的な設計判断**。直すべきねじれではない。
2. **課金はしない。** 返金対応や課金まわりの面倒を避けたい。**無料プレイ＋広告収益のみ**。
3. **ライトにリリースして緩く収益を得たい。** 温度感は年間100万円もらえれば御の字。

**結論を先に書く。この条件なら、狙うべきはアプリストアではなく web ゲームポータルである。** 単一HTMLという現在の形が、そのまま提出物になる。

## この文書の役割

受け取り側のチャットは、ゲーム本体の開発経緯を一切持っていない。この文書だけで議論を始められるよう、事実・監査・市場データ・選択肢を自己完結でまとめてある。

実装セッション側の立場は「作った本人による自己採点」なので、当然バイアスがある。**受け取り側には、ここに書かれた推奨を疑うところから始めてほしい。** 特に次の3点。

1. web ポータル（Poki / CrazyGames 等）の主流は短時間のカジュアルゲームで、**20〜30分・恒久ロストのローグライクは想定客層と合わない**。それでも推奨に値するか。
2. 「英語化が必須」という判断は、日本国内だけを狙う選択肢を過小評価していないか。
3. 広告を増やす（デス時インタースティシャル等）提案は、このゲームの「搾り取らない」性格を壊さないか。

### 過去2版から撤回した判断

- **第1版**「遊び味は買い切りなのに配信形態はF2P」というねじれ指摘 → **撤回**。買い切りの遊び味を無料配布するのは矛盾ではない。
- **第2版** 1回の解放課金（C案）を推奨 → **撤回**。課金しないと決まったため。

## 3. 監査 — 「無料・広告のみ」前提で並べ直す

広告収益モデルでは **滞在日数がそのまま売上**になるため、第2版（買い切り前提）とは重み付けが大きく変わる。**変更点を明記する。**

### 【致命】アートと音が無い

ヴァンパイアサバイバー系の手触りは、**当たった感触・音・画面の揺れ**でほぼ決まる。今のビルドはそこが完全に空欄で、現状の面白さは**低いのではなく測定不能**。

広告モデルでは、これは品質問題ではなく**直接の収益問題**になる。手触りが悪ければ D1 で落ち、DAU が積み上がらない。DAU が積み上がらなければ広告は1円にもならない。

### 【致命】誰も遊んでいない

22スイートが保証しているのは「壊れていないこと」だけで、**面白いことの証拠は1つも無い**。D1・セッション長・離脱階層、どれも観測値がゼロ。到達数がボトルネックである以上、**外部の人間に触らせる仕組みが無いこと自体が最大の収益リスク**。

### 【重】日本語のみ（新規・重要度高）

UIテキストは日本語だけ。広告 eCPM は米国・欧州が最も高く（リワードで米 $19.63 / 欧 $8–15、Tier-3 は $1–3）、web ゲームポータルの流入も大半が英語圏。**日本語のみだと、単価の高い市場に一切届かない。**

翻訳対象は約8,450字（コード内コメントは対象外）。英語で 4,000〜5,000語程度で、**文字列を一箇所に集める作業込みで数日規模**。広告モデルにおいては、これが最も費用対効果の高い作業になりうる。

### 【重】明日また開く理由が無い（第2版から格上げ）

デイリー報酬もシーズンもランキングも無い。

第2版（買い切り前提）ではこれを【低】とした。買ってもらえばゴールだったからだ。**広告のみだと逆転する。D30 リテンションがそのまま年間売上になる。**

ただしデイリー報酬は設計思想（得だけの物を置かない）と正面衝突する。**「無料の贈り物」ではない復帰動機**を探すべきで、以下は原則を壊さない：

- **週替りの縛り** — 贈り物ではなく制約。毎週ルールが変わる
- **週間ランキング** — 最深記録だけを競う。報酬なしでも成立する
- **他人の遺体** — 非同期で他プレイヤーの死亡地点が出現する

### 【重】収益導線が薄すぎる（第2版から格上げ）

リワード3種（ガチャ2回・仲間蘇生・階段回復2回）のみで、**すべて「1探索につき2回まで」と自分で上限をかけている**。プレイヤーに優しい設計だが、**唯一の収益源をわざわざ絞っている**状態でもある。

第2版では課金が主だったので【中】としたが、広告が唯一の収益源になった以上、ここは正面から設計し直す対象になる。具体案は第6章。

### 【重】コンテンツ量が見かけ倒し

50階・6層・12ジョブと並ぶと厚く見えるが、**敵の挙動の型は4つしかない**。8系統は属性と色の違いで、動き方は同じ。ボスも共通ムーブを共有。50階を6層で回すので、後半は「暗くなった同じ景色」を2周する。

広告モデルでは**コンテンツの厚さ＝滞在日数＝売上**。飽きが来る階層がそのまま収益の天井になる。

### 【中】セッション長がポータルと合わない（新規）

web ゲームポータルの主流は数分で終わるカジュアルゲーム。**1探索20〜30分・恒久ロストという構造は、想定客層と噛み合わない可能性がある。**

緩和策としては、階段（5階ごとの帰還ポータル）が自然な中断点になっているので、**セッションの区切りとして前に出す**ことは可能。ただし根本的な相性問題は残る。

### 【低】Unity移植の負債（第2版から大幅格下げ）

C#は「引き撃ちの抑制」の時点で凍結し、以降の10機能以上が未反映。**しかし web 配信を選ぶなら、この負債は当面返済しなくてよい。** 単一HTMLがそのまま製品になる。ネイティブアプリを出す判断をした時点で初めて発生するコスト。

### 【低】操作が移動だけ＝腕前の天井が低い（格下げ）

有料なら「浅い」と書かれるリスクだったが、無料なら重みが下がる。むしろ **web ポータルではキーボード不要・マウス／タッチだけで遊べることが明確な利点**になる。

### 【中】IP表現のリスクは「作り」ではなく「宣伝」にある

仕組みの継承自体は問題ない。危ないのは**ストア／ポータルの説明文・SNSでの紹介**で、「移植」「リメイク」「公式」に読める表現、および元作の固有名詞。現状の実装はすべて独自命名なので、守るべきはこの一線だけ。

### 【強み】死んでも前進する設計

秘石と鉱石は拾った瞬間に口座へ入るので、**どんな死に方をしても潜った時間が永続強化に変わる**。恒久ロストで人が辞める最大の理由を構造的に潰してある。広告モデルでは、これは**そのままリテンション＝売上**に効く。

### 【強み】判断の密度が同ジャンルより高い

イベントに「得だけの選択肢を置かない」縛りを通し、採掘は立ち止まる代償を持ち、鍛造の重打は明確な取引になっている。**オート戦闘なのに毎階で意思決定が発生する**のは珍しい。

### 【強み】単一HTMLであること（新規・最大の資産）

これまで「まだ活かせていない利点」としか書いてこなかったが、**広告のみ・ライトに出す**という条件では**これが最大の資産**になる。Unity移植も、ストア審査も、ATT同意も、プライバシーマニフェストも、課金実装も、返金対応も、すべて不要。**今日そのまま提出できる形式で完成している。**

## 5. 選択 — 配信チャネルの比較

課金をしないと決めた時点で、論点は「収益モデル」ではなく「どこに置くか」に移る。

| 観点 | A / web ゲームポータル | B / ネイティブアプリ（ストア） | C / 自前サイト・itch.io |
|---|---|---|---|
| 提出物 | **単一HTML（現状のまま）** | Unity移植が必要 | 単一HTML |
| 集客 | **ポータルが供給**（月3億〜10億プレイ） | 自力。実質ゼロ | 自力。実質ゼロ |
| 広告の取り分 | 45〜60% | 100% | 90〜100% |
| 必要な事務作業 | ポータルSDK組込・審査 | 開発者登録・審査・ATT同意・プライバシー対応 | ほぼ無し |
| 課金・返金 | **無し** | 無し（課金しないため） | 無し |
| 立ち上がりの速さ | **数週間** | 数ヶ月（移植込み） | 即日 |
| 想定客層との相性 | **悪い**（短時間カジュアルが主流） | 良い | 中 |
| 収益の見込み | 好調なら月 $200–2,000 | DAU次第。集客できなければゼロ | ほぼ期待できない |
| 総合 | **推奨**。取り分は削られるが集客を買える | 現時点では時期尚早 | 実験・計測用として併用 |

**A案を推す理由は取り分ではなく集客。** 取り分は半分になるが、**自力では絶対に集められない規模のトラフィックが供給される**。到達数がボトルネックである以上、そこを解決できる唯一の選択肢になる。

**B案を落とす理由。** Unity移植（書き直しに近い）＋ストア審査＋ATT同意＋プライバシー対応というコストを払って、**集客は何ひとつ解決しない**。「ライトにリリース」という条件とも真逆。web で手応えが出てから判断すればよい。

## 6. 推奨 — 順序と、広告の具体設計

### 順序

**第1段階：計測（今すぐ・無料）**
itch.io か自前サイトに現状のまま置き、SNS等で数十人に触ってもらう。取るのは **D1・セッション長・離脱階層**の3つ。ここで得られる「実際に飽きが来る階層」は、以降すべての判断の土台になる。

**第2段階：英語化（数日規模）**
UIテキスト約8,450字を英語化。単価の高い市場に届く条件であり、web ポータルの審査に通る前提でもある。文字列を一箇所に集める作業を同時にやっておく。

**第3段階：手触りの最小実装**
アートと音。ここが【致命】である以上、ポータルに出す前に最低限の当たり判定表現・SE・画面の揺れは要る。フル制作ではなく、**気持ちよさが測定可能になる最小限**でよい。

**第4段階：ポータルへ提出**
CrazyGames / Poki / GameDistribution。取り分と集客規模の組み合わせで選ぶ。並行して自前サイト版も残す（直接流入は取り分100%）。

**ネイティブアプリ（Unity移植）は、第4段階の結果を見てから判断する。**

### 広告の具体設計

現状のリワード3種は**そのまま残す**。見れば得しかしない形は、無料プレイヤーとの関係として正しい。そのうえで足す。

**1. デス時インタースティシャル（最重要）**
死亡は既に自然な区切りで、そこで挟む広告は搾取に感じられにくい。eCPM も $14 前後と高い。ただし恒久ロストのゲームは死亡が頻繁なので、**必ず頻度制限をかける**：

- 最短間隔 **3分以上**（連続死亡で連打されない）
- **第3階層より手前では出さない**（初回体験を守る）
- 1セッションあたり上限を設ける

上記の「毎ステージ出すと15〜25%離脱」という数字は、この制限を守らなかった場合の姿。

**2. 拠点にバナー**
探索中は**絶対に出さない**（画面が狭く、被弾に直結する）。拠点・倉庫・鍛造所などのメニュー画面のみ。単価は低いが、滞在時間は確実にある。

**3. リワードの上限を少し緩める**
「1探索につき2回」を、たとえば「5階ごとに1回」に変える。プレイヤーの選択肢が増え、深く潜るほど機会が増える。**押し付けではないので、性格は変わらない。**

### 触ってはいけない線

> **秘石・鉱石・強化レベル・潜在の入手を、広告の見返りにしない。**
> 「潜った時間が必ず前進に変わる」という、このゲームで唯一よくできている部分が、広告を見た量の関数に置き換わってしまう。

### 期待値について正直に

必要なのは常時 200〜600 DAU。**主要ポータルで「好調な」部類に入れば月 $200〜2,000（年¥38万〜380万）で目標圏内**だが、その「好調な」がふるいであり、20〜30分・恒久ロストという構造はポータルの主流客層と噛み合わない。

**下振れた場合は年数万円規模**になる可能性が高い。そこも織り込んだうえで「緩く」であれば、この道は合理的。

## 7. 論点 — abyss 側で決めてほしいこと

**Q1. ポータルの客層とのミスマッチをどう見るか**
Poki / CrazyGames の主流は数分で終わるカジュアルゲーム。20〜30分・恒久ロストのローグライクが受け入れられる見込みをどう評価するか。ミスマッチなら、A案の前提が崩れる。

**Q2. 英語化を第2段階に置く判断は正しいか**
広告単価は英語圏が圧倒的に高いが、日本語圏だけを狙って Yahoo!ゲーム・ふりーむ等の国内ポータルに出す選択肢もある。規模は小さいが競合も少ない。

**Q3. デス時インタースティシャルは「搾り取らない」性格を壊すか**
現状の広告は3種とも「見れば得する」もので、強制表示は1つも無い。ここに初めて**プレイヤーの意思と無関係な広告**が入る。収益上ほぼ必須だが、ゲームの人格が変わるとも言える。

**Q4. アートと音にいくらまで使うか**
【致命】である一方、収益見込みが年数万〜100万円の規模だと、外注費が回収できない可能性がある。自作でどこまでやるか、あるいは投資しないと決めるか。

**Q5. どこで撤退・切り替えを判断するか**
「web版で3ヶ月やってDAUがN人未満なら打ち切る／別の形に変える」という基準を先に決めておきたい。緩くやる場合ほど、終わり方を決めておかないと惰性で続いてしまう。

## 数字の扱いについて

本文中のベンチマークはすべて他社タイトルの公開集計値であり、本作の売上予測ではない。ARPDAU・eCPM・リテンションはジャンル・地域・時期で大きく振れる。本作は外部プレイのデータを1件も持っていないため、**いかなる収益試算も現時点では成立しない**。

ARPDAU の $0.03〜0.15 という帯は、eCPM と DAU あたり視聴回数から組んだ**桁を掴むための仮置き**であって、集計値として出典を確認できたものではない。

また、収益配分・税務（広告収入も課税対象）・法務（IP表現の可否）については専門家の判断ではない。特にIPまわりは、実際に配信を決める段階で弁護士に確認することを前提として読むこと。
