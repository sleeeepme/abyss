# 拠点背景：採用素材と実装

## 本編への接続

`proto/index.html` の `HUB_BG_SHEET` に正本の `loop-spritesheet.png` を同一バイトで埋め込み、既存のCanvas再生を更新した。素材の再生成・再配色は行っていない。UIは独立した上位レイヤー。背景はpointer-eventsを持たない。

- ネイティブ544×306（16:9）、72フレーム、12fps、6秒ループ。
- シート6528×1836、12列×6行。フレーム位置は `sx=(frame%12)*544`、`sy=Math.floor(frame/12)*306`。
- `layoutHubBg()` で表示領域の高さ100%に合わせ、横幅も同じ倍率で拡縮する。横中央・上端0。狭い画面では左右を切り取り、16:9より横長では左右に余白を残す。高さを優先するため、従来の整数倍率coverは使用しない。
- `ResizeObserver` で背景の親要素のサイズを監視。画面回転と、既存のvisualViewport対応によるURLバー開閉時の高さ変更に追従する。
- Canvasは `imageSmoothingEnabled=false`、CSSは `image-rendering:pixelated`。既存の拠点チルトシフト設定は維持。
- 拠点を離れるとrAF停止、戻ると再開。モーション軽減では先頭フレームを表示。画像読み込みが後になってもonloadで描画する。

## キャラ・歩行面・演出（2026-10-18）

`index.html` の `HUB_SCENE` を原画座標の正本とする。中心(271,170)、洞窟の敷居(270,100)。キャラ・入場・出発・ワープを、背景と同じ544×306座標と倍率で配置する。拠点キャラは16×16論理ドット、足元(8,14)アンカー。絵のドット倍率は固定し、移動位置は小数で毎フレーム補間する（原画1pxへ丸めると歩行がカクつくため）。背景を差し替える場合は、歩行面・柱・敷居も新しい絵に合わせて再測定する。

通行可能な範囲は広場と上下の通路。柱4本とその外側は侵入不可。経路の全区間で足元半径2pxを検査し、必要な場合は迂回する。通行判定は拠点の演出用で、ダンジョンの当たり判定には接続しない。

`proto/hubworldtest.mjs` と `proto/towntest.mjs` で倍率・足元・通行判定・出発・ワープ・操作を検証。詳細は `docs/VISUAL_DEVELOPMENT.md` と `output/hub-world-alignment/quality/`。
