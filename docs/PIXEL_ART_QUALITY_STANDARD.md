# ピクセルアートの品質判断基準

2026-09-21。モンスター、人物、物、背景、UI、動きを評価するための作業基準。**この文書の存在は、評価能力・作画能力の獲得を証明しない。** 根拠となる実見例と評価の失敗は [研究記録](art-quality-study/2026-09-21/README.md) に残す。

## 判定を混ぜない

1. **表現としての完成度**：形・役割・特徴が伝わり、画素の配置がそれを支えるか。
2. **案件への適合**：要求されたサイズ感、視点、線、頭身、雰囲気、表示環境に合うか。
3. **ユーザーの採否**：明示された採用・保留・不採用。AIの再評価で変更しない。

良い背景でもTinyRPGの小型敵の見本とは限らない。採用済み画像にも改善余地はあり得るが、そのことを理由に無断で差し替えない。

## 絵を見た時の順序

### 1. 説明を読まず、何がどうなって見えるかを書く

原寸と実際の表示倍率を見る。キャラクターなら「頭が右上、腕が前、後ろの布を引きずる」、部屋なら「扉から机へ通れる、家具が床に立つ」と具体的に書く。部位が読めない時、設定を補って読めたことにしない。ただし怪物に標準的な首・腹・関節が無いだけでは欠点ではない。

### 2. 主役と、主役を支える形を見る

最初に視線が向く箇所、その後に読める箇所を特定する。歯の大きい怪物は口、道具は用途を示す先端、背景は場所の骨格が主役になり得る。省略された所より、主役に必要な情報が残っているかを優先する。

### 3. 色面が形を説明しているか確認する

明部は額なのか、上面なのか、金属の反射なのか。暗部は陰面なのか、口なのか、部位の重なりなのか。理由を局所で示す。全てを立体的に塗る必要はない。平面のアイコン、1-bit、巨大な口を中心にした記号表現に、写実的な陰影を要求しない。

### 4. 拡大して画素の判断を見る

線の階段が狙う曲率や尖りを支えるか、部位の境界が偶然接していないか、明暗の帯が輪郭をなぞるだけになっていないか。1pxが目・牙・反射・粒などの仕事をしていれば残す。単に点が孤立していること、暗線が局所で2pxになることを自動的な失敗としない。

### 5. 同じ用途・近い寸法の基準と比較する

画面上の大きさを揃える時も、不等倍率や縮小で原寸を潰さない。原寸の違う作品は「構図」「空間」「素材の反射」など比較可能な観点だけを見る。小型キャラに大型の絵の細部量を要求しない。

## 仕分けの意味

|判定|必要な根拠|
|---|---|
|良い完成例|目的が伝わる箇所を挙げ、画素・面・余白がどう寄与するか説明できる|
|基準未達|伝わるべき内容を損なう箇所を特定できる。例：掌と顎が接続して読み違える|
|用途不適合|絵自体の長所は成立しているが、要求された寸法・視点・密度等が違う|
|判定保留|解釈が割れる、原寸がない、動きを見ていない、適切な比較対象がない|

無理に全画像を高/低の二群へ押し込めない。「最下位だから低品質」「AIレビューで高得点だから完成」と扱わない。

## 用途によって観点を変える

|対象|先に見ること|低く評価する具体的な状態|
|---|---|---|
|小型キャラ|姿勢、特徴の誇張、顔・装備・肢の関係|腕と顎の誤接続、特徴を均等な面に埋める、身体全体が部品の列に見える|
|肖像|目鼻の配置、表情、顔の向き|陰影の装飾は増えても、顔の向きや表情が破綻する|
|物・アイコン|用途を示す部分、向き、材質|剣と杖の識別点が潰れる、全材質が同じ丸い反射になる|
|タイル|敷き詰めた時の連続性、密度の変化|単体は細かいが格子状の反復が目立つ、全面が同じ濃さで騒がしい|
|背景・部屋|空間、前後、光、焦点と余白|家具が浮く、遠近の明暗が競合する、移動できる面が判別できない|
|UI・文字|小さくした時の識別、文字の空洞と間隔|OとD等の形が潰れる、枠や装飾の方が操作内容より強い|
|アニメーション|意図した動き、重心、接地、速度変化|部位が突然別の形へ飛ぶ、足が滑る、ただ伸縮するだけで動作にならない|

文字は小型アルファベットの比較表まで観察した。実際の文章表示・ゲームUI操作性は未検証。アニメーションも一部の静止キーポーズと限られた再生観察であり、全ジャンルを習得済みとは扱わない。

## 規則に見えて、単独では品質を決めないもの

- 色数、解像度、輪郭の有無、孤立画素数、制作ツール、製作者名、制作時間。
- 一様な強いコントラスト。遠景や背景では弱いコントラストが奥行きと主役の分離を作る。
- 描き込みの量。必要な形を残した省略と、形が分からない省略を区別する。
- リアルな解剖・素材。小さい漫画的表現に、目的の違う写実基準を押しつけない。
- 滑らかさやフレーム数。速度の強弱とポーズの関係を実再生で確認する。

## 今回の誤判定から加える条件

- 匿名12点レビューではTinyRPG Blood Monsterを相対的に弱い群へ、未採用グラブを強い群へ置いた。ユーザーの基準を識別する検査として失敗。詳細は校正記録を参照。
- 「口が巨大で胴が単純」な表現を、胴体が解剖的に説明されていないという理由だけで落とさない。
- 「節が区別できる」という一項目だけで、身体全体の連続性・動勢・独自の見せ場まで合格したことにしない。
- 同じ12点を正体開示後に並べ直しても、それは説明の修正であり、未見作品への識別成功ではない。
- AIの意見が一致しても人間の独立評価ではない。意見が割れる時は根拠を点検し、加点を合算して欠点を帳消しにしない。
