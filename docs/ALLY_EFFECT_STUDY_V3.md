# 味方エフェクト試作 v3

2026-09-12。通常攻撃の約2倍速化と、ヒット粒子・グローを調整。

参考：[Etriel Athanasia / Testing a new Skill](https://x.com/etrielathanasia/status/2071969254292009180)。ブラウザで動画の複数フレームを観察し、細い放射状の光の筋と周囲の柔らかな発光を参考にした。以下の数値は試作用の設定であり、映像からの実測ではない。

- 振りの表示時間をv2の半分に短縮。命中基準は120 → 60 ms、斬撃の軌跡は65–390 → 32.5–195 ms。
- 命中で斬撃22個、打撃28個の粒子を生成して描画。初速200–430 px/s、指数減速6/s。前方を多めにし、少量は側方・後方にも散らす。
- 粒子は攻撃の高速化とは別の時計で200–390 msの余韻を持つ。細長い光と小さな破片を混ぜ、白・黄を中心に少量の青白い粒子を加えた。
- グローは9 px / 0.45と2.5 px / 0.60の2層。その上にベタ塗りの鋭い本体を描画。旧版の陰影・色の縁取りは戻していない。
- 周期は試作画面のみ0.85秒。ゲーム本体の攻撃頻度、ダメージ、当たり判定、AIは変更していない。

描画：`proto/ally-effect-study.js`。プレビュー：`proto/ally-effect-study.html`。
書き出し：`output/ally-effects-v3/ally-slash-strike.gif` と `ally-slash-strike-slow.gif`。
GIFでは同じ形状の描画コマンドを記録してPillowでラスタライズ。グローはアルファのガウスぼかしで再現し、ブラウザのCanvasフィルターとは微小な差があり得る。

確認：JS構文、GIFを全フレーム再デコード、80・160・280 msの形状とグローを目視。
