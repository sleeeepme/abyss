# 味方の斬撃・打撃エフェクト試作 v1

2026-09-11。確認ページ: `proto/ally-effect-study.html`。

## 参考と解釈

参考は [Sephiriaの公式Steamページ](https://store.steampowered.com/app/2436940/Sephiria/?l=japanese) の公開トレーラー。
白い攻撃軌跡、黄〜橙の着弾光、ピクセルの輪郭を観察した。全武器・全エフェクトの解析や素材抽出はしていない。
以下の形状、配色、時間は観察に基づく独自の試作値で、原作の実測値ではない。

- 斬撃: 不透明な白の三日月、淡い青緑の外縁、細く分離する残光。着弾点だけに小さな暖色の火花。
- 打撃: 短い前方の圧縮線、白い芯と琥珀色の星形、分断された床の衝撃輪、小さな破片。
- 両方とも広いブラーを使わず、低解像度の描画を拡大する。攻撃方向は4方向で比較できる。
- 味方は既存の剣士・重騎士の待機スプライト。攻撃ポーズの新規作画や武器アニメーションは含まない。

## 試作タイミング

| 要素 | 時間 |
|---|---|
| 表示上の予備動作 | 0–120 ms |
| 命中基準 | 120 ms |
| 斬撃の軌跡 | 75–320 ms |
| 打撃の主閃光 | 120–300 ms |
| 破片 | 120–520 ms |
| 描画の上限 | 580 ms |
| 自動再生周期 | 1.25秒 |

「強い一撃」は形状を1.22倍にする表示比較。「命中」を外すと着弾光・破片・的の反応が消える。スロー、停止、1/60秒コマ送り、位置指定に対応。モーション軽減設定時は静止状態で開始する。

## ファイルと本体への接続

- `proto/ally-effect-study.js`: 再利用用の描画関数 `AllyEffectStudy.render(ctx, {kind, age, x, y, angle, scale, heavy, hit})`。kindは `slash` / `blunt`、ageは秒、座標は描画ピクセル、angleはラジアン。Canvasの状態はsave/restoreで保持し、ゲームの乱数を消費しない。
- `proto/ally-effect-study-preview.js`: 比較画面、的、見た目だけの踏み込み・後ずさり。
- `proto/ally-effect-study.html`: ローカルで直接開ける比較ページ。外部通信なしで表示できる（参考リンクを開く場合を除く）。

現段階はサンプル。`proto/game-feel.js` と本体の戦闘処理は変更していない。
採用時は `drawFeelSwing` の `slash` / `blunt` と、命中確定時の `feelImpact` を別々に接続する。サンプルの120 msを本体の命中時刻に流用せず、本体の攻撃イベントと残り時間に合わせる。特に敵の演出と混同しないよう、味方の発生源を識別する必要がある。
ダメージ、成長、報酬、敵AI、当たり判定、シミュレーションの速度に変更はない。

JavaScriptの構文確認、およびChromeでのページ表示・160 msの着弾比較・コマ送り・強弱と命中の切替を確認。
