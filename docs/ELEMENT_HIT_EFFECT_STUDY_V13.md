# 属性ヒットエフェクト v13

雷ヒットの形と強さを保ち、消えるまでの時間をv12より少し延ばした確認版。

- 主電撃の表示を約0.21秒から約0.29秒へ延長した。
- 着弾中心の発光を約0.095秒から約0.12秒へ延長した。
- 飛散片の余韻を約0.32秒から約0.40秒へ延長した。
- 後半は太さを落とし、形が残り続けないよう段階的に減衰する。
- 炎、冷気、魔法と全武器の攻撃軌跡はv12から変更していない。

単体ヒットのGIFは `output/element-hits-v13/`、全武器へ重ねたGIFは `output/combined-element-effects-v13/` に出力する。
