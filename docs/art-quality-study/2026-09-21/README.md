# ピクセルアートの品質判別・第1回校正

2026-09-21。ユーザーの「制作前に品質の高低を判断できるようにしてほしい」に対する調査。新しいゲーム素材は制作しない。

## 現在地

作者の教程と実作品を、キャラクター・顔・物・材質・タイル・室内・風景・動きに分けて観察する。同時に既存12画像を匿名で評価した。**匿名評価は基準と逆転する結果があり、判断力の獲得を証明できていない。** 読んだ件数やチェック表の完成を、作画能力・識別能力の向上と呼ばない。

これは観察記録と再利用する判断手順の更新であり、モデルの重みの追加学習ではない。世界の全作品を網羅した調査でもない。

外部作品の高品質判定は、知名度や色数によらず、画像で確認した長所を理由として記録する。教程の途中画像は途中段階の教材であり、作者の力量が低いという分類にしない。

実見した内容を8組の作者・18項目に整理した。18は作品点数や独立記事数ではなく、比較図・教材・作品群をまとめた観察項目数。外部の実作品を一律に低品質と呼ぶ分類はせず、欠陥の比較教材と自作の基準未達例を低品質の具体例として使う。

## 制作再開前の扱い

前回のボグ系4体はユーザーから品質不足を指摘された稿として保持する。過去の採用・暫定採用は変更しない。既存の基準との比較を飛ばして新しい対象へ進まない。判断が割れた項目は保留とし、AI同士の多数決や自己採点で合格にしない。
