# 添付洞窟マップの再構成 V5

参照の赤茶の足場、紫の岩、青緑の水に合わせた別プレビュー。既存V4とゲーム本体は変更していません。

- ネイティブ256×256、8×8固定タイル、32×32セル。
- 床の大きな柄は4×4セル単位の組で使用。無地差分と組み合わせる。各柄を自由に入れ替える完全なオートタイルではない。
- 床・縁272枚、崖4枚、水16枚。岩・階段・滝・石碑・結晶などは40×40の16スロットから別配置。
- 上段、下段、右階段を手配置。elevationは視覚上の段差を記録したデータで、本編の衝突や移動ルールではない。
- JSONとTiledのTMJ/TSJ、RGBAパーツシートを同梱。
- 4倍PNGは実際にニアレストネイバーで拡大。全画素の一致を検証。

参照との残差：岩のシルエットと床の輪郭には差があり、水路も参照より直線的です。完全なトレースではなく、再利用タイルによる構成・配色の再現試作です。ブラウザで参照と並べて確認できます。

素材は組み込みimagegenで参照付き生成。`output/cave-reference-v5/generated-atlas.png`が生成原本。固定タイル化、背景色除去、スライスと縮小は`build.cjs`。元画像を丸ごとマップに貼っていません。

生成指示：参照の配色と粗いピクセル表現に合わせ、4×4等分の素材シートを制作。1行目は赤茶の床4種、2行目は紫灰の岩4種、3行目は崖2種・階段・滝、4行目は青いルーン石碑・桃色結晶・青い発光キノコ・冒険者。文字なし、暗い単色背景、各セル32px相当の描き込み量。

再生成順序：build.cjs → capture.cjs → verify.cjs。verifyで装飾を含むTiledデータを仕上げます。
