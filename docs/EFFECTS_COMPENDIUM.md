# エフェクト図鑑（実装状況一覧）

2026-09-15 作成。通常攻撃・武器技・大技・スキル技・敵の攻撃を横断した演出（エフェクト）の一覧。
`[済]` = ゲーム本体に実装済み、`[未]` = 未実装・演出未設計。カテゴリを追加・更新したら、この表と
`proto/effects-compendium.html`（実機コードによる実装済みエフェクトのプレビュー付きブラウザ版）の両方を直す。

参照元：`docs/VISUAL_DEVELOPMENT.md`（採用済み戦闘エフェクトの実機接続）、`docs/WEAPON_ELEMENT_EFFECT_INTEGRATION.md`、
Claude側プロジェクト資料 `abyss-武器技システム.md` / `abyss-敵とボス設定書.md`。

## 1. 通常攻撃（8種・全て `[済]`）

`ally-effect-study.js` の武器別描画を `game-feel.js` の `drawSwing` / `drawShot` から呼ぶ。
`sword` と `axe` は同じ「剣・斧」演出を共有。属性ヒット（炎・雷・冷気・魔法・無属性）は
`WEAPON_ELEMENT_EFFECT_INTEGRATION.md` の対応で本体接続済み。

| 武器 | base | 演出グループ |
|---|---|---|
| 剣 | `sword` | 剣・斧（共有） |
| 大剣 | `great` | 両手剣・大剣 |
| 短剣 | `dagger` | 短剣 |
| 斧 | `axe` | 剣・斧（共有） |
| 槍 | `spear` | 槍・刺突 |
| 弓 | `bow` | 弓 |
| 戦鎚 | `mace` | 戦槌 |
| 杖 | `staff` | 魔弾・杖攻撃 |

属性ヒット（4種＋無属性）：炎 / 雷 / 冷気 / 魔法 / 無属性。`feelImpact` に確定ダメージ種別と追加属性を渡し、
対象座標へ専用ヒットを生成（敵→味方・味方→敵の両方向で共通）。

## 更新の仕方

1. 効果を作り込んだら該当行の `[未]` → `[済]` に書き換える。
2. 大技・スキル技の詳細が決まったら、このファイルと `proto/effects-compendium.html` の両方に反映する
   （Claude側プロジェクトの「エフェクト図鑑」アーティファクトにも同期を依頼できる）。
3. 新しい演出ファイル・study系ドキュメントを追加したら、参照元としてここにも1行足す。
4. `proto/effects-compendium.html`（＋`effects-compendium-app.js`）に新しいエフェクトを組み込む
   手順（`ITEMS`配列の書き方、プレビューAPIの契約）は `docs/EFFECTS_COMPENDIUM_INTEGRATION.md` 参照。
