盾とパリイ

・🛡を押さえている間だけガード。離せば解ける。盾の性能に応じて被ダメージを減らす。
・敵の攻撃が当たる瞬間に押すとパリイ。 攻撃が消滅し、盾も減らない。押しっぱなしでは発生しない。
・ガード中は移動が鈍る。この game では移動が回避なので、これが代償。
・両手武器（大剣・弓）はガード中に攻撃できない。片手武器なら構えたまま戦える。
・盾が大きいほど軽減は高いが、パリイの受付時間は短い。

武器種と属性

属性と状態異常

状態異常は蓄積式。同じ属性で殴り続けると溜まって発症する。
敵の頭上の小さな点が、今かかっている状態異常。

弓と杖 足を止めるほど強い

飛び道具は撃った瞬間の足の状態で威力が変わります（近接は変わりません）。
止まって撃つ 満額　/ 踏み込みながら 95%　/ 横に動きながら 85%　/ 引き撃ち 62%
弓は「下がりながら撃つ武器」ではなく、間合いを保って足を止める武器です。 引き撃ちは今も有効ですが、いちばん遅い倒し方になります。
今の撃ち方と倍率は画面右下に常時表示されます。 減衰した一撃はダメージ数値がくすんで「↓」が付きます。

攻撃エフェクト 属性ごとに形が違う

色だけでなく形を変えてあります。動きの速い画面では色は読めないので、 「弧を薙いだのか、まっすぐ突いたのか」で属性が分かるようにしています。
追加属性（業火・雷光・氷結）が乗っていると、主属性の形の上にその色の粒が重なります。

ボスと恩寵

・5階層ごとにボス。10の倍数は大ボス、 それ以外の5の倍数は中ボス。
・ボスを倒すまで階段は封鎖される。倒すと帰還ポータルが開く。
・名前とHPゲージは一撃入れてから出る。それまでは金の輪と王冠だけが目印。
・ボスはとても大きい。当てやすいが、殴られる範囲も広い。
・赤い図形が出たら範囲攻撃。図形の中がそのまま当たる範囲で、 溜めている間ボスは止まっているので歩いて外へ出れば避けられる。
　叩きつけ＝足元の円／ 薙ぎ払い＝正面の扇（横に回る）／ 散弾＝全方位の弾／ 波動＝広がる輪（内側に入る）
・範囲攻撃もパリイできる。構えた瞬間だけ。
・HPが半分を切ると激昂。速くなり、技が1つ増える。
・撃破すると恩寵を3つ提示され、1つ選ぶ。 効果はそのキャラが死ぬまで続き、街に戻っても消えない。
・同じ恩寵を選び直すと重ねがけになる。
・第50階層には初めの供物がいる。倒しても階層は続く。
・恩寵は誰に与えるかを選べる（あなた／仲間）。

ユニークな敵

・紫の輪と固有の名前を持つ一体が、まれに道中に紛れている。
・エリートより強く、中ボスよりは弱い。倒すと恩寵が確定で手に入る。
・階段は塞がないので、勝てないと思ったら無視して降りてよい。
・ミニマップに紫の点で出る。

仲間

・道中に？の付いた人影がいる。タップか足元のボタンで 能力を見てから加入を決める。
・名前は一人ひとり違います。同じジョブでも別人です。
・加入時点で恩寵を持っていることがあります。 あなたのレベルが高いほど、数もレア度も上がります。 加入前の画面に出るので、見てから決められます。
・良い恩寵と良い装備を抱えた者には二つ名が付きます （見習いの → 腕利きの → 高名な → 伝説の）。 中身から計算しているので、育てば二つ名も上がります。
・最大3名。武器種はジョブごとに固定で、能力はあなたより一段弱い。
・指示は出せない（操作は移動だけ）。勝手に追ってきて勝手に戦う。
・仲間が増えると経験値は頭数で分配される。ただし総量は人数ぶん少し増える。
・倒れると失われる。1人につき1回だけ広告で蘇生できるが、 Lv.1に戻り装備をランダムに失う。
・仲間はあなたに属している。あなたが死ねば全員失われる。
・あなたの足跡を辿ってついてきます（壁で置いていかれません）。
・HPが減ると自分から退きます。ジョブごとに引き際と回避率が違います （盗賊は回避32%で、薄い装備のまま前に出られます）。
・僧侶は後衛です。近接の仲間がいるあいだはその後ろに陣取り、 攻撃には参加しません（祈りの回復は続きます）。
・街の能力強化「仲間の練度」で、仲間全員の能力が上がります。 口座側の強化なので、これから拾う仲間にも効きます。

道中のイベント

階層にはときどき調べられる物が置かれています（ミニマップに色付きの点）。
どれも「やるか、やめるか」の一択で、得だけの物はありません。無視して降りるのも常に正解です。
📦 忘れられた荷：装備3点。開けると敵が湧く
⛲ 癒しの泉：全員全快。ただしこの階層の敵が速くなる
🕯️ 古びた祭壇：最大HPの10%を永久に払い、3つの恩寵から1つを選ぶ
🏺 賭博の壺：未鑑定品を賭けて55%でレア度が1段階上がる

踏破済みの階層

最深到達より4階層以上 浅いところは「踏破済」になり、 移動速度が1.45倍になります（仲間も一緒に速くなります）。
一度きちんと抜けた場所を、毎回同じ速度で歩き直す必要はないからです。

欠片 死んでも失わない

敵が◆欠片を落とします。拾った瞬間に貯まるので、 そのあと死んでも失いません。
欠片は能力強化の対価です（金では買えません）。
どんなに酷い死に方をしても、潜った時間は必ず能力強化に変わります。
エリート・ユニーク・ボスほど多く落とし、深いほど増えます。

呪い（週替わりの縛り）

街で任意に掛けられる縛りです。掛けなくても構いません。
毎週3つ提示され、週が変わると入れ替わります。重ねがけできます。

縛りと報酬は必ずセットです。
飢餓（階段回復が効かない → 欠片+60%）/ 奔流（敵が速い → 黒鉄+80%）/ 重圧（最大HP-25% → 発見力+60）/ 静寂（大技が使えない → 経験値+50%）/ 孤独（仲間なし → 金+100%）/ 薄氷（被ダメージ+40% → 欠片・金+40%）/ アビスの呼び声（敵のレベル+4 → 全報酬+30%）

潜った時点で確定し、途中では外せません。
デイリー報酬のような「得だけの物」は置かない方針なので、 復帰の理由は取引の形にしてあります。今週の3つでどこまで潜れるか、が毎週リセットされます。

遺体は時間で朽ちる

死んだ場所に残る遺体は、実時間で風化します。
24時間までは満額、そこから72時間で完全に消えます。
回収できる道具・金・黒鉄が、朽ちた割合ぶんだけ減ります。 すぐ取りに行けなくても1日は猶予があります。

大技

10階ごとの大ボスを倒すたびに、大技を1つ覚えます（全5種）。
セットできるのは1つだけ。探索中は画面右下の丸ボタンで発動します。
震撼（周囲を殴る）/ 瞬歩（跳んで無敵）/ 業火（前方へ炎）/ 守護（全員の被ダメージ減）/ 崩落（画面内すべて）

技レベルは欠片で上げられます（街 → 能力強化）。 威力が上がり、リキャストも短くなります。
操作は移動だけ、という原則の唯一の例外です。だから枠は1つ、 リキャストは20〜40秒、狙いを付ける操作はありません。増えるのは「ここで切るかどうか」の判断だけです。

地形の危険

第10階層から、層のテーマに合わせた危険な床が現れます。
溶岩（炉の層）/ 毒沼（水の層）/ 濡れ石（跡の層）/ 石の棘（石の層）/ 胞子溜り（根の層）/ 虚（白の層）

通れますが、立っているあいだダメージと状態異常を受け、種類によっては足が遅くなります。
敵にもまったく同じだけ効きます。 避けるだけの物ではなく、敵を誘い込めば武器にもなります。 階段の周りには置かれません。

回復アイテム

敵がまれに消耗品を落とします（丸い形で落ちています）。道具屋でも買えますが、装備より割高です。
癒しの軟膏（HP40%）/ 深緑の薬（全快）/ 浄めの香（状態異常を全部消す）/ 共鳴の雫（全員35%）

持ち物を開いてタップで使用。
使わなかった消耗品は持ち帰れません。 溜め込んで連打できると、頻度を絞った意味がなくなるためです。

仲間の成長と装備

仲間は Lv.10 / 20 / 30 / 40 / 50 で専用技を1つずつ覚えます（最大5つ）。
攻撃力や被ダメージ軽減のほか、パーティ全員に掛かる技もあります。
Lv.50 の技はジョブごとの大技で、リキャストを経て自動で出ます。
回転斬り・守護陣・五月雨・焦土・幻影・恩寵・聖域・三重召喚・崩落。 操作は移動だけという原則を崩さないため、ボタンは増やしていません。

装備を付け替えられます。街なら倉庫から、探索中なら持ち物から。
武器はジョブの武器種のみ（狩人に大剣は持たせられません）。防具は自由です。 街の「仲間」欄か、探索中は持ち物画面の仲間をタップしてください。

大ボスを倒すと新しいジョブが現れるようになります。
聖騎士・召喚士・大魔導士。既存のジョブより派手なぶん、出現率は低めです。

倒れた仲間の広告蘇生は、5階進むごとに権利が戻ります。

階段の見つけ方

未踏の階層では、階段は最初は見えません。 自分の目で見つけるまで、画面にもミニマップにも出ません。
入った瞬間に出口が見えていると、やることが 「最短距離で ▼ へ歩く」に決まってしまい、部屋を見る理由が消えるからです。

ただし 40 秒 ほど経つと 階段の気配（方向を指す矢印）が出て、 そこから 20 秒かけてだんだんはっきりしていきます。迷い続けることはありません。

踏破済みの階層では、最初から見えています。 もう知っている場所を探し直す意味は無いので。

黒鉄と打ち直し

アビスの各階層に 鉱脈 がランダムに 1〜3 ヶ所あります（ミニマップにも出ます）。
近づいて 掘ると黒鉄が手に入りますが、掘っているあいだは動けません。 移動すると中断し、殴られても中断します。
深さで等級が変わります： 粗鉱（〜16階）/ 精鉱（12〜34階）/ 深鉱（28階〜）

黒鉄は持ち帰らないと自分の物になりません。 死ぬと半分を遺体に落とし、残りは失われます（欠片とは逆の性格です）。
欠片は「潜った時間そのものの対価」なので絶対に失いません。 黒鉄は「持ち帰るという判断の対価」なので失います。だから引き返す判断が生まれます。

装備中の武器を、黒鉄＋ゴールドで +10 まで鍛えられます。
・街の鍛冶屋＝口座のゴールド。定価（鍛冶屋のレベルで割引）
・道中の鍛冶場（鉱脈とは別の場所にある）＝そのランで拾ったゴールド。1.5倍
　鍛冶場では黒鉄で装備をまとめて修理もできます（武器・防具・盾・装飾品。等級は問いません）。仲間のぶんも。
道中の金はどのみち死ねば消えます。今叩くか、持ち帰って安く叩くかの判断です。

+3・+6・+9 でランダムに技が1つ付きます（武器種に合う物だけが出ます）。
疾撃（攻撃速度）/ 遠間（範囲）/ 連撃（もう一撃）/ 大振り（扇）/ 貫き（貫通）/ 鋭刃（会心）/ 重打（威力↑速度↓）/ 吸命 / 堅牢（耐久）/ 熾火・走雷・凍て（属性）

鍛えた武器も、装備したまま死ねば他の装備と同じく失われます。 道中の鍛冶場が割高なのは、それでも「今使う」ほうが得な場面を作るためです。

広告でできること

・街のガチャ：持ち込む武器か護符が手に入る（1日5回まで）
・仲間が倒れたとき：蘇生（Lv.1・装備ランダムロスト／1人1回だけ）
・階段で「全員回復」：あなたと仲間のHPが全快する （1回の探索につき2回まで・探索ごとに戻る）
回復の回数を絞っているのは、消耗が積み上がるからこそ 「引き返すか、もう1階降りるか」の判断が生まれるからです。休憩ではなく手札として使ってください。

層 10階層ごとに変わる

色だけでなく、床の様子・漂う物・明かりの届く距離・部屋の広さ・出やすい敵が まとめて変わります。層の名前が「何を持っていくべきか」のヒントになります。
階段では次の層を予告します。一周すると最初の層に戻り、さらに暗くなります。

敵の系統

形＝行動、色＝属性。三角なら突撃、赤なら獣、というように読む。
狙っている敵の弱点は画面上部に出る。
系統は深く潜るほど増える。1階層に同時に出る系統は最大でも 1〜4種で、序盤は 1 種類だけ。まず「獣」を覚えてから次を覚える。
回避ボタンはありません。敵の赤い予兆は歩いて避けるか パリイします。

ルール

・敵の周りに赤い輪が広がったら攻撃の予兆。歩いて離れる。
・街では能力強化と装備の購入ができる。これはロストしても消えない。
・生きて帰ると帰還報酬がもらえる。深いところから戻るほど大きい。
